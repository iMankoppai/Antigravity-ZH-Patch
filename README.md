# Antigravity 中文补丁 v26.1

适用于 **Windows x64 / Antigravity 2.18.1** 的本地中文补丁。

## 下载

**[下载完整汉化包](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/download/v26.1/Antigravity-ZH-v26.1-Windows-x64.zip)** · [查看发布页](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/tag/v26.1)

完整 ZIP 附带 Node.js 24.21.0 运行环境和中文使用说明，无需另外安装 Node.js 或 PowerShell 7。

## 安装和升级

1. 先安装 Antigravity **2.18.1**，并完全退出软件，包括托盘进程。
2. 下载完整 ZIP，右键选择“全部提取”，解压到准备长期保留的目录。
3. 双击 `安装汉化.cmd`，选择这台电脑上实际安装的 `Antigravity.exe`。
4. 从桌面“Antigravity 中文版 v26”或解压目录里的 `启动中文版.cmd` 启动。修订版沿用这个启动入口名称。

**升级旧版：**先完全退出软件，在旧补丁目录运行 `恢复英文.cmd`，再安装完整的新包。请保留整个解压目录，并避免同时运行不同目录的两份补丁。安装位置可以与其他电脑不同。详见 [使用说明.txt](使用说明.txt)。

## 恢复英文

完全退出 Antigravity 后，运行 `恢复英文.cmd`。它会停用本补丁、移除其桌面入口，并在版本和校验匹配时恢复本机的原生资源备份。随后使用软件原来的入口启动。

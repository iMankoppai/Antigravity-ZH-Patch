# Antigravity 中文补丁 1.0.2

适用于 **Windows x64 / Antigravity 2.18.1** 的本地中文补丁。

## 下载

**[下载完整汉化包](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/download/v1.0.2/Antigravity-ZH-1.0.2-Windows-x64.zip)** · [查看发布页](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/tag/v1.0.2)

完整 ZIP 附带 Node.js 24.21.0 和中文使用说明，无需另外安装 Node.js 或 PowerShell 7。

## 安装和升级

1. 先安装 Antigravity **2.18.1**，完全退出软件，包括托盘。
2. 下载完整 ZIP，右键“全部提取”。升级旧补丁时，建议先运行旧包的 `恢复英文.cmd`。
3. 双击 `安装汉化.cmd`，选择这台电脑的 `Antigravity.exe`。
4. 补丁会安装到软件目录下的 `中文补丁`；例如软件在 `D:\Antigravity`，补丁就在 `D:\Antigravity\中文补丁`。
5. 以后从开始菜单、任务栏固定图标或程序本体打开，都会自动加载汉化。

不创建桌面快捷方式。请保留安装后的 `中文补丁` 文件夹；安装完成后可移走下载解压目录。安装目录受保护而提示拒绝访问时，可用同一账号以管理员身份运行安装入口。详见 [使用说明.txt](使用说明.txt)。

## 本次更新

- 普通入口自动加载汉化，不依赖专用启动器或常驻后台注入进程。
- 开启“保留在系统托盘”时，点击 X 隐藏原窗口；左键双击托盘恢复原窗口，保留当前页面和任务。
- 托盘菜单及运行中代理数量汉化，右键“退出”仍正常结束程序。

## 汉化功能

**1462 个词条**，覆盖设置、对话历史、定时任务、插件和 MCP、文件与差异审阅、命令面板、登录状态及项目教程等。9 个主题预设中文化，MCP 目录包含 98 条服务说明。

分类词典支持热更新；格式错误或译文冲突时保留上一份有效内容。保留对话与文档正文、草稿、名称、代码、路径、终端输出和成果内部内容。

## 恢复

先完全退出 Antigravity（包括托盘），再运行对应入口：

| 入口 | 作用 |
| --- | --- |
| `恢复英文.cmd` | 停用汉化并恢复本机原始资源 |
| `恢复原关闭方式.cmd` | 恢复 X 的原有关闭行为，保留汉化和中文托盘 |
| `恢复原托盘行为.cmd` | 撤回双击恢复及菜单汉化，保留其他功能 |
| `恢复原汉化加载方式.cmd` | 改回专用入口加载，此后使用 `启动中文版.cmd` |

备份在接收电脑安装时生成。软件更新或资源被其他程序修改后，恢复工具会停止，避免旧备份覆盖新资源。

# Antigravity 中文补丁 v26

适用于 **Windows x64 / Antigravity 2.18.1** 的本地中文补丁。

## 下载

**[下载完整汉化包](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/download/v26/Antigravity-ZH-v26-Windows-x64.zip)** · [查看发布页](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/tag/v26)

完整 ZIP 附带 Node.js 24.21.0 运行环境和中文使用说明，不需要另外安装 Node.js 或 PowerShell 7。下载文件的内容与桌面上验证过的 `Antigravity-中文补丁-v26-跨电脑使用包.zip` 完全一致；下载附件名使用英文以兼容 GitHub。

## 安装和使用

1. 先安装 Antigravity **2.18.1**，并完全退出软件，包括托盘进程。
2. 下载上面的完整 ZIP，右键选择“全部提取”，解压到准备长期保留的目录。
3. 双击 `安装汉化.cmd`，选择这台电脑上实际安装的 `Antigravity.exe`。
4. 安装完成后，通过桌面“Antigravity 中文版 v26”或解压目录中的 `启动中文版.cmd` 启动。

安装位置可以与其他电脑不同。请保留整个解压目录，中文启动入口需要使用其中的文件。完整操作和常见问题见 [使用说明.txt](使用说明.txt)。

## 功能

- **1444 个词条**，覆盖设置、对话历史、定时任务、插件和 MCP 目录、文件查看、差异审阅及命令面板等界面。
- 9 个主题预设中文化，悬停可查看英文原名；MCP 目录收录的 98 条服务说明中文化。
- 项目设置、评论提示、技能说明和搜索空状态、定时任务表单及任务运行状态补齐中文。
- 分类词典与热更新；词典格式错误时继续使用上一份有效内容。
- 保留对话与文档正文、草稿、名称、代码、路径、终端输出和成果内部内容。
- 对匹配版本的原生文件夹选择窗口标题进行适配，并保留本机恢复备份。

## 恢复英文

完全退出 Antigravity 后，运行解压目录里的 `恢复英文.cmd`。它会停用这份补丁、移除其中文启动入口，并在版本和校验匹配时恢复本机的原生资源备份。随后使用软件原来的入口启动。

## 适用范围和验证

- 已验证 **Antigravity 2.18.1 / Windows x64**；其他版本和系统不在本次适配范围内。安装器会拒绝不匹配的应用版本。
- **67 项浏览器回归检查、9 项隔离安装与恢复检查通过**；压缩包解压后的 22 个文件校验一致。
- 已完成一次只回复文字的真实任务测试；登录、真实插件安装以及涉及工具执行的任务状态主要通过源码和离线模拟检查，尚未逐项实测。
- 当前应用未向普通用户提供 PDF 和笔记本预览的开启入口；补丁不启用应用内部实验功能。
- 这是非官方汉化补丁，不包含 Antigravity 软件本体。软件升级后需重新检查兼容性。

# Export and share

## Start from a brief

Know where each file will play, on what screen and speaker, and who gets it next: a viewer, a platform or another editor.

## What makes it work

Delivery is the last edit. Every file will be re-encoded, shrunk to a thumbnail, played on a phone speaker or opened by a stranger. Make choices so the work survives that. The bar for any handoff: the person can use it without asking you a question.

- Export from main, the version the person approved.
- Make every version from the project, never from another export.
- Watch the exported file, not the timeline.

## Craft

**One master, many versions.** The master is clean: no platform crops, no squashed loudness. Keep text and captions on their own tracks so a textless version is one export away; every re-cut, new language or new end card starts there.

**Sound.** Loudness for delivery lives in `/invideo-timeline`.

**Check the file.** Watch it top to bottom on the device it is made for: sound off for social, picture off for audio, with `references/check-your-video.md`.

**Names.** Never the word final in a name. Versions only go up, and the name says what the file is: `Acme_Launch_60s_9x16_v07`. Label review copies so nobody mistakes a draft for the delivery.

**The note.** Every delivery goes with a few lines: what each file is, where it plays, and what changed since the last one. It turns a pile of files into a handover.

## By type

| Video | Focus |
|---|---|
| MP4 | The master at the project's own frame rate. No black bars; the player fits the frame. |
| Vertical | A new edit, not a crop. Reframe each shot, keep text out of the app's buttons, and open on a frame that works as the thumbnail. |
| Audio-only | Re-edit for the ear. Fix every "as you can see", say what the screen showed, open on a strong line, tighten pauses that only worked under a picture. |
| Stills | Pick, don't grab. Step a few frames for open eyes and no blur. Full resolution, PNG, no text, in each crop it will need. |
| Thumbnail | A promise the opening keeps. One subject, a few words that don't repeat the title. Read it at stamp size. |
| Share page | The final first, each file labelled by where it plays. |
| Project file | One timeline that is plainly current. Note what is temp, what is open and which fonts it uses, and send a reference export so they can check their copy frame for frame. |

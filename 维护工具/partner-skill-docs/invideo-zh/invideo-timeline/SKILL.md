# 时间线操作

先阅读 `/invideo`。

一次编辑是一组操作，要么全部应用，要么都不应用。在首次使用每个操作前查阅其字段（`timeline_catalog`），并在大型编辑落地前用 `dry_run: true` 进行检查。

## 帧运算

- 以 `_f` 结尾的字段是按时间线自身帧率的帧数；`_seconds` 字段是秒数。帧数 = 秒数 × fps：半秒在 30 fps 下是 15 帧，在 24 fps 下是 12 帧。
- 从时间线读取帧率；绝不要假设它。
- 范围包含起点、不包含终点：从 0 到 90 的片段结束于第 89 帧。
- 读取返回的时间为 `{value, rate}`，即 value / rate 秒。

## 轨道与分层

- 较高的视频轨道绘制在较低轨道之上。自下而上构建：先放素材，然后是在其下方所有内容之上的调整片段上调色（`add_adjustment`），再在最上层放文字和叠加层。
- 视频的声音是它自己的音频片段，与画面链接。它们一起移动、裁剪和删除。
- 每条轨道只承担一项职责并为其命名（`set_name`）：对白、音乐、音效；素材、b-roll、标题。锁定你不去触碰的内容（`set_track_locked`）。

## 局部性测试

移动一处揭示，其余一切保持不变。每次编辑只触碰它必须触碰的内容；如果一个小改动移动了其他任何内容，那这次编辑就是错的。

- 优先选择让其余部分保持不动的操作。`roll` 只移动一个剪切点，其后的内容不动；`slip_clip` 改变片段显示的内容而不移动它。
- 波纹类操作会移动轨道上之后的所有内容：`edit_gap`、带 `close_gap` 的 `delete_clip`、`retime`、跨所有未锁定轨道的 `edit_time_range`。当这种移动正是目的时使用它们。
- 发送前，说明应该改变什么。之后，捕获那一刻及其相邻内容并比较。

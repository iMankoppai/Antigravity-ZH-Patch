# 分享给合适的人

使用已连接的 Spacefast 工具。在代码仓库中工作时，保留无关的文件和改动。

如果任务需要某个现有 Space 且其身份不明确，调用 `choose_space`。将选中的 Space 作为目标。选中并不代表批准发布或其他改动。

在执行管理操作前，阅读 [references.md](references.md) 中的 MCP 调用、审批与工作模式规则。

1. 确定该 Space 以及请求的目标受众。保留该项请求之外的访问权限。
2. 阅读 [references.md](references.md) 中的**管理访问权限（Manage access）**。在更改访问权限前，先阅读当前的权限。
3. 应用满足请求的最小范围访问变更。验证预期的操作主体和路径。
4. 对于分享链接，验证预期的访客体验并报告其范围和有效期。

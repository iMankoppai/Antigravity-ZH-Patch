# 入门访谈与数据探索

本技能引导你完成 Looker 用户入门的初始阶段：
访谈用户以了解其目标，并探索其 BigQuery 数据
以找出适合做仪表板的候选对象。

## 前置条件

-   用户必须有一个全新的 Looker Core 实例。
-   用户必须已安装 `gcloud` 并已针对 GCP 完成认证。

## 操作说明

### 1. 访谈用户（阻塞步骤）

你必须先访谈用户，以了解其目标并获取
目标 GCP 项目和数据集。在提出这些问题并收到用户的明确回复之前，
不要运行任何 `gcloud` 或 `bq` 命令。

提出如下一组问题：

> "欢迎使用 Looker！为帮助你快速上手，我将引导你连接
> 数据、设置项目并构建第一个仪表板。
>
> 为确保我们构建的内容与你高度契合，能否告诉我：1.
> 你进行 Looker 探索的主要目标是什么？（例如销售分析、用户
> 行为、库存跟踪、支持指标）2. 你想使用的数据位于哪个 BigQuery 项目和
> 数据集？3. 是否有你特别关注的特定指标
> （例如总营收、活跃用户）或维度（例如产品类别、
> 地区）？"

**停下并等待**用户回复。本轮不要调用任何工具。

### 2. 探索 BigQuery 数据

只有在用户已回答访谈问题并提供目标
项目/数据集之后，才继续使用 `bq` CLI 探索其 BigQuery 数据。

> [!IMPORTANT] **不要假定任何表命名约定**（例如 `dim_` 或
> `fct_` 前缀）。虽然部分数据集会使用它们，但很多并不使用。你必须通过分析其 schema（列、类型）和
> 内容来识别维度表和事实表，而不能仅凭表名判断。

1.  列出项目中的**数据集**：

    ```bash
    bq ls --project_id={gcp_project_id}
    ```

    查找与用户业务领域匹配的数据集（例如 `ecommerce`、
    `analytics`）。

2.  列出所选数据集中的**表**：

    ```bash
    bq ls {gcp_project_id}:{dataset_name}
    ```

    识别候选表：

    -   **维度表**包含参考或查找数据（例如 `users`、
        `products`、`categories`、`locations`）。查找用于描述
        实体的表。
    -   **事实表**包含事务或事件数据（例如 `orders`、
        `order_items`、`events`、`sessions`、`payments`）。查找包含数值
        指标和时间戳的表。

3.  **检查关键候选表的表结构**：

    ```bash
    bq show --format=prettyjson {gcp_project_id}:{dataset_name}.{table_name}
    ```

    查找时间戳、用于聚合的数值字段，以及用于
    关联表的外键。

### 3. 提出入门目标

根据用户的输入和你的数据探索，提出一个具体、
可执行的仪表板目标。

示例提案：

> "我已探索你的数据集 `{dataset_name}`，发现了一些很棒的表格：-
> `{table_1}`（包含带营收和时间戳的事务数据）-
> `{table_2}`（包含产品维度，如类别和品牌）
>
> 我建议我们以**销售概览仪表板**作为入门目标。它将包括：1. 随时间变化的**总营收**（按日/周）。2. 按销售量排名的**热门产品
> 类别**。3. **订单状态分布**（例如
> 已完成、待处理、已取消）。
>
> 如果这听起来不错，我将继续设置 Looker CLI 并
> 连接这些数据！"

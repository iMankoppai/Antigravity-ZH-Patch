# Intercom 分析

使用 Intercom MCP 服务器来分析客户对话、查找联系人和公司、识别支持模式，并调查客户问题。

关于每个 MCP 工具的详细工具参考、查询 DSL 语法、搜索策略和字段级文档，请参阅 `references/mcp-tools.md`。

## 模式分析工作流

当用户要求分析其支持数据中的模式或趋势时，遵循以下工作流：

1. **界定范围。** 弄清用户想要分析什么 —— 一个时间段、话题、客户细分或对话状态。如果不清楚就询问。

2. **获取有代表性的样本。** 搜索符合该范围的对话。检索至少 10–20 个对话以建立有意义的模式。如果第一页不足则分页。

3. **阅读对话详情。** 对于每个相关对话，获取完整对话以阅读实际消息。仅凭搜索结果中的摘要通常不足以进行模式分析。

4. **识别反复出现的主题。** 按以下方式对对话分组：
   - 常见话题或关键词
   - 提及的产品领域或功能
   - 报告的错误消息或症状
   - 采用的解决方式
   - 解决所需时间

5. **量化并总结。** 用计数和比例呈现发现（例如“15 个对话中有 8 个提到超时错误”）。优先突出最常见的模式。

6. **建议行动。** 基于模式，提出具体的后续步骤 —— 要创建的知识库文章、要调查的缺陷，或流程改进。

**输出产物：** 生成一份具有以下结构的 markdown 报告：

- **主题摘要** —— 已识别主题的表格，包含对话计数及其占总数的百分比
- **主要问题** —— 3–5 个最常见的问题，附有代表性的对话摘录
- **建议行动** —— 根据发现的模式，按优先级排列的具体后续步骤清单

## 问题调查步骤

当用户要求你调查某个特定客户问题或事件时：

1. **识别客户。** 按邮箱、姓名或 ID 查找联系人。获取其完整画像以了解其账户上下文（套餐、公司、位置、自定义属性）。

2. **追溯时间线。** 搜索来自该联系人的所有对话，按日期排序。获取每个对话，构建其交互的按时间顺序的叙述。

3. **检查多客户影响。** 搜索来自其他联系人、提及相同症状、错误消息或受影响功能的对话。这可以确定该问题是孤立的还是广泛的。

4. **检查对话详情。** 对于最相关的对话，通读完整会话串，包括内部备注。队友的备注通常包含诊断信息和根因分析。

5. **总结发现。** 呈现：
   - 客户交互的时间线
   - 核心问题及任何错误消息
   - 尝试过什么、什么解决了问题（如果有的话）
   - 是否有其他客户受影响
   - 指向相关对话的链接

**输出产物：** 生成一份时间线摘要，包含：

- **客户上下文** —— 联系人详情、公司、套餐和账户属性
- **交互时间线** —— 对话的按时间顺序列表，含日期、渠道和结果
- **影响评估** —— 该问题是否影响其他客户，附指向相关对话的链接

## 最佳实践

- **先宽后窄。** 先做一般性搜索以了解全貌，再应用筛选条件聚焦于重要内容。

- **始终引用对话链接。** 在引用具体对话时，包含其 ID，以便用户能在 Intercom 收件箱中找到它们。格式为：`Conversation #12345`。

- **说明数据局限。** 如果搜索结果已分页而你只看到了第一页，请说明。如果数据不足以支持某个结论，请明确说明确认该结论需要什么。

- **尊重新鲜度。** MCP 服务器返回来自 Intercom 工作区的实时数据。结果反映当前状态 —— 如果用户询问历史趋势，注意自事件发生以来对话状态可能已改变。

- **有效组合工具。** 典型的工作流涉及用 `search` 或 `search_conversations` 查找相关条目，然后用 `get_conversation` 或 `get_contact` 获取完整详情。不要试图仅凭搜索结果回答复杂问题。

- **从容处理空结果。** 如果搜索没有结果，建议替代方案：用更少或不同的关键词扩大查询、尝试不同的对象类型（联系人而非对话，或反之）、检查邮箱地址或姓名是否有拼写错误，或先运行一次不加筛选的搜索以确认数据存在。

- **为便于浏览而格式化搜索结果。** 将结果呈现为整洁的表格。对于对话：ID | 主题 | 状态 | 最后更新（含相对时间戳）。对于联系人：ID | 姓名 | 邮箱 | 最后活跃时间。显示结果后，主动提出获取完整详情（例如“要我调出对话 #12345 的完整会话串吗？”或“我可以获取完整画像 —— 想看看吗？”）。

## 故障排查

### MCP 服务器断开连接
错误：工具调用因连接/超时错误失败
原因：MCP 服务器无法访问或认证已过期
解决方案：重新认证、检查网络、稍后重试

### 搜索返回 0 个结果
错误：预期有匹配项时结果集为空
原因：查询过于狭窄、字段名错误，或没有匹配的数据
解决方案：放宽筛选条件、尝试不同的对象类型、先运行不加筛选的搜索

### 工作区没有对话
错误：所有对话搜索都返回空
原因：新/未使用的工作区或访问范围限制
解决方案：确认工作区有数据，改为尝试联系人/公司搜索

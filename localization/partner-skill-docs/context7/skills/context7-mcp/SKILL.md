当用户询问库、框架或需要代码示例时，使用 Context7 获取最新的文档，而不是依赖训练数据。

## 何时使用本技能

在以下情况下启用本技能：

- 用户提出安装或配置类问题（"How do I configure a Next.js proxy?"）
- 用户请求涉及库的代码（"Write a Prisma query for..."）
- 用户需要 API 参考（"What are the Supabase auth methods?"）
- 用户提及具体框架（React、Vue、Svelte、Express、Tailwind 等）

## 如何获取文档

### 步骤 1：解析库 ID

调用 `resolve-library-id`，参数为：

- `libraryName`：从用户问题中提取的库名
- `query`：要在该库文档中查找的内容（可提升相关性排序）

### 步骤 2：选择最佳匹配

从解析结果中，依据以下标准选择：

- 名称与用户所要求的内容精确或最接近
- 基准评分越高，表示文档质量越好
- 如果用户提及版本（例如 "React 19"），优先选择特定版本的 ID

### 步骤 3：获取文档

调用 `query-docs`，参数为：

- `libraryId`：选定的 Context7 库 ID（例如 `/vercel/next.js`）
- `query`：要在该库文档中查找的内容，限定为单一概念

如果用户的问题跨越多个不同概念（例如路由、认证和缓存），请使用同一库 ID 针对每个概念分别发起一次 `query-docs` 调用，除非问题涉及这些概念之间如何相互作用——合并查询会稀释排序，导致每个主题都只返回浅层结果。

### 步骤 4：使用文档

将获取到的文档融入你的回答：

- 使用最新、准确的信息回答用户的问题
- 包含文档中相关的代码示例
- 在相关时注明库的版本

## 指南

- **要具体**：描述要在该库文档中查找的内容，但每个查询限定为单一概念
- **每次查询一个主题**：将多主题问题拆分为多次 `query-docs` 调用——先解析一次库 ID，然后按概念分别查询，除非问题涉及这些概念之间如何相互作用
- **版本意识**：当用户提及版本（"Next.js 16"、"React 19"）时，如果解析步骤提供了特定版本的库 ID，则使用之
- **优先官方来源**：当存在多个匹配时，优先选择官方/一手包，而非社区分叉

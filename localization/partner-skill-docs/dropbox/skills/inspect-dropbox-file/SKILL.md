# 检查 Dropbox 文件

使用此技能在汇总、比较、共享、恢复或整理 Dropbox 文件或文件夹之前了解它。

## 工具

- `get_file_metadata`
- `fetch`
- `list_shared_links`
- `get_shared_link_metadata`
- `search`
- `list_folder`

## 工作流

1. 从用户请求中识别目标文件或文件夹。
2. 若目标不明确，使用 `search` 或 `list_folder` 查找可能的匹配。
3. 对所选项目调用 `get_file_metadata`。
4. 若用户询问内容、摘要、提取或分析，对文件使用 `fetch`。
5. 若用户询问版本历史或回滚选项，说明当前 Dropbox MCP 工具不提供版本列表或恢复操作。
6. 若用户询问共享或访问，使用 `list_shared_links`；在声称共享链接列表完整之前，只要响应指示 has_more 或返回游标就继续。
7. 若用户提供 Dropbox 共享链接或询问特定链接，使用 `get_shared_link_metadata`。

## 输出

仅汇总与用户请求相关的细节。包含：

- 名称和路径
- 文件或文件夹类型
- 大小和修改时间（可用时）
- 共享/链接状态（相关时），包括共享链接分页是否完整
- 版本历史限制（相关时）
- 已抓取内容的摘要（相关时）
- 建议的下一步操作（若用户要求）

## 安全

这是只读工作流。不要创建链接、更改共享、复制、移动、删除或恢复内容。若用户要求进行变更，请说明预期操作并切换到相关的 Dropbox 技能。

## 良好触发

- “这个 Dropbox 文件是什么？”
- “总结一下这个文件。”
- “检查这个文件夹是否已共享。”
- “给我看版本历史。”
- “这个文档上次更新是什么时候？”

## 不适用场景

- 用户只想搜索或浏览。使用 `find-dropbox-content`。
- 用户想创建共享链接或检查共享链接状态。使用 `share-dropbox-content`。
- 用户想添加查看者或直接与指定收件人共享。说明在所需 MCP 工具被暴露之前无法进行收件人共享。
- 用户想恢复某个版本。说明在 Dropbox 恢复工具被暴露之前无法恢复。

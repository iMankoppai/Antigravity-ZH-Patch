# 查找 Dropbox 内容

使用此技能定位相关的 Dropbox 文件和文件夹，不做任何更改。

## 工具

- `search`
- `list_folder`
- `get_file_metadata`

## 工作流

1. 仅在用户请求过于宽泛而无法执行时，才澄清搜索目标。
2. 对于宽泛的关键词、标题、文件类型或自然语言搜索，使用 `search`。
3. 当 `search` 返回游标且需要更多结果时，仅使用该游标继续 `search`。
4. 当用户指定文件夹或想浏览某个位置时，使用 `recursive=false` 的 `list_folder`。
5. 当 `list_folder` 返回游标且需要更多文件夹结果时，仅使用该游标继续 `list_folder`。
6. 在呈现最终建议之前，对强候选使用 `get_file_metadata`。

## 输出

优先返回最佳匹配。对每个结果，包含：

- 名称
- 对象类型：文件或文件夹
- 路径或稳定标识符
- 修改时间（可用时）
- 为何匹配该请求
- 任何模糊之处或信心保留

## 安全

不要创建、复制、移动、删除、恢复、下载或共享内容。若用户在找到内容后要求执行其中某项操作，请切换到相关的 Dropbox 技能。

## 良好触发

- “在 Dropbox 里找第四季度规划演示文稿。”
- “在 Dropbox 中搜索入职文档。”
- “这个文件夹里有哪些文件？”
- “找关于发布计划的近期 PDF。”
- “客户合同在哪里？”

## 不适用场景

- 用户已提供确切文件并希望检查其内容。使用 `inspect-dropbox-file`。
- 用户明确要求创建共享链接。使用 `share-dropbox-content`。
- 用户要求添加查看者或直接与指定收件人共享。说明在所需 MCP 工具被暴露之前无法进行收件人共享。
- 用户要求恢复或找回内容。说明在 Dropbox 恢复工具被暴露之前无法恢复。

## Datadog MCP 服务器

本文档所引用的 Datadog MCP 服务器的 id 是 `datadog-antigravity`。即使存在其他 Datadog 服务器，你也必须使用这个特定的服务器。

**如果插件 Datadog MCP 服务器的工具不在你的可用工具中，你仍然必须运行此技能 —— 不要就此断定 Datadog 不可用。** 工具缺失意味着服务器需要设置或暂时断开连接；它们不是无法完成请求的证据。下面的 `datadog-server-state` 检查是判断实际状况的权威来源。

## 使用其他方法访问 Datadog

如果插件的 Datadog MCP 服务器出现问题，**不要**建议用户使用不同方式（如 Datadog 网页）访问 Datadog 信息。**相反**，先修复插件的 MCP 服务器，因为它能提供更好的智能体体验。只有当用户**明确**引导你朝那个方向时，才考虑其他方法。

## 设置流程

检查 `datadog-server-state`（见 `mcp-settings.md`）：

- **working** —— 继续处理用户的请求，且不要提及此检查。
- **not-working** —— 不加任何前言，告诉用户服务器已设置但无法工作，指示他们运行 `/ddconfig`，然后停止。
- **not-setup** —— 服务器需要首次设置。**不要**尝试使用不同方法收集数据。**不要**尝试任何进一步的 MCP 调用：在设置完成之前它们都会失败。

在下面与用户沟通时，用平实的语言描述服务器状态。不要透露检查了什么、发现了什么，或任何实现细节，如文件内容或变量值。

### 设置完成后 Datadog 能提供什么

Datadog 是一个可观测性平台。此技能完成设置后，智能体将获得 MCP 工具，可直接查询生产数据 —— 用户无需离开 AI 客户端或打开浏览器。以下是可以实现的功能示例：

- 搜索和筛选应用日志
- 查询基础设施和应用指标
- 检查分布式追踪中的延迟或错误
- 列出仪表板、监控器和告警
- 调查事件和值班呼叫页面

这些 MCP 工具是在 AI 客户端内访问 Datadog 数据的主要方式。在设置完成之前，**这些工具都不存在**。智能体无法看到、列出或调用它们。

### 步骤

按顺序执行以下步骤：

1. **询问域。** 告诉用户 Datadog MCP 服务器需要设置，从 `mcp-settings.md` 的站点到域表格中展示可用站点及其 MCP 域，并询问要使用哪个域。用户可能直接回复一个 MCP 域、一个站点代码、一个 URL 或其他内容 —— 使用 `mcp-settings.md` 中的映射规则将答案解析为 MCP 域。如果有歧义，请求澄清。

   遵循 `mcp-settings.md` 中的“遵循脚本”规则。特别是，不要预览下面第 3 步的后续说明（重新加载、重新认证等）—— 那一步会在恰当的时刻逐字给出这些内容。

2. **应用更改。** 使用 `mcp-settings.md` 中的确定性路径推导来定位注册文件。在注册文件中，将确切的字符串 `not-setup` 替换为解析出的 MCP 域。遵循 `mcp-settings.md` 中的编辑规则。

   更改前：

   ```
   "serverUrl": "https://not-setup/v1/..."
   ```

   更改后（us1 的示例）：

   ```
   "serverUrl": "https://mcp.datadoghq.com/v1/..."
   ```

   **在报告成功之前验证编辑。** 在你推导出的确切路径上重新读取注册文件，确认 `not-setup` 已消失且解析出的 MCP 域已存在。在此重新读取确认之前，不要告诉用户任何内容已被初始化。如果 `not-setup` 仍然存在，说明编辑落在了别处 —— 使用 `mcp-settings.md` 中的规则重新推导路径并再次应用更改，而不是报告成功。

3. **告诉用户** Datadog MCP 服务器已初始化，并请他们按照以下步骤操作：

   在 Antigravity 应用或 IDE 中：
   1. 打开 Agent 设置（Mac 上为 ⌘,，Windows/Linux 上为 Ctrl+, —— 请显示当前操作系统对应的正确快捷键），然后转到 **Customizations**
   2. 在已安装的 MCP 服务器下，点击刷新按钮
   3. 点击 `datadog-antigravity` 服务器旁边的 **Authenticate**，在浏览器中登录，然后把授权码粘贴到设置中并点击 **Submit**

   在 Antigravity CLI 中：
   1. 运行命令 `/mcp` 并重新加载 MCP 配置
   2. 在提示时对 `datadog-antigravity` 服务器进行认证

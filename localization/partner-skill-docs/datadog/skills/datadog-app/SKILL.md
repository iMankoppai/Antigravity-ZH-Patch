# Datadog Apps

仅使用此技能来**搭建一个新的 Datadog App 的脚手架**。它不涵盖其他内容。

一旦应用脚手架搭建完成，所有后续指引 —— 本地开发、认证、部署、发布、CI/CD、后端函数、数据访问、升级和故障排查 —— 都位于所生成项目的 `AGENTS.md` 和 `docs/agents/` 文件中。

## 参考路由

| 用户任务                | 阅读                            |
| ------------------------ | ------------------------------- |
| 创建新的 Datadog App | `references/getting-started.md` |

## 边界

- 此技能仅涵盖脚手架搭建。项目创建完成后，到此为止。
- 不要从此技能提供认证、部署、发布、CI/CD 或应用逻辑方面的指引 —— 请改为阅读项目的 `AGENTS.md`。
- 不要在此技能中涉及 Datadog 包/平台的开发。

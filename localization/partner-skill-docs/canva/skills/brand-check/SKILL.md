# 品牌检查器

将设计与用户的品牌套件对比，逐点报告它在哪里遵循品牌、在哪里偏离。这是 `canva-design-feedback` 的专业化、品牌感知版本：同样以只读的“读取设计，然后点评”为核心，但评分标准是品牌套件。它**绝不编辑**设计。

## 品牌套件数据缺口——先读这里

`Canva:list-brand-kits` 据文档会返回品牌套件**ID、名称和缩略图**。它可能不返回机器可读的调色板（十六进制值）和字体家族。你的方法取决于你实际拿回的东西：

- **若套件暴露颜色/字体** → 将这些确切的十六进制代码和字体名作为评分标准（精确检查）。
- **若它只暴露缩略图/名称** → 你无法做精确的十六进制/字体匹配。退回到对照套件缩略图的**视觉**比较，并请用户粘贴其品牌颜色（十六进制）和字体，以便你能精确检查。明确说明，没有这些，颜色/字体方面的发现只是近似的。

绝不臆造品牌颜色或字体。若你没有真实值，就如实说明。

## 读取设计的实际颜色和字体

`Canva:get-design-content` 只返回文本——不返回颜色或字体。

- 一个**只读**的编辑事务（`Canva:start-editing-transaction` → 检查 → `Canva:cancel-editing-transaction`，始终取消）能可靠给出元素**文本、位置和尺寸**。
- **颜色和字体不会被该事务可靠暴露**——经测试：它往往只返回文本 + 位置 + 尺寸，没有颜色/字体属性。因此**缩略图是颜色和排版的**主要证据。使用载荷恰好包含的任何样式数据，但除非它确实在载荷中，否则绝不要把设计的十六进制值或字体当作事实断言。

因为品牌套件（见上方缺口）和设计本身都常常缺少机器可读的颜色/字体，品牌检查往往是一种**视觉**比较（设计缩略图 vs. 品牌套件缩略图）加上用户提供的调色板/字体。使用 `Canva:get-design-thumbnail` 检查徽标放置和整体视觉语气。

## 工作流

### 步骤 1：解析设计
短链接 → `Canva:resolve-shortlink`；完整 URL → 提取 ID；原始 `D...` ID → 直接使用；否则询问。

### 步骤 2：获取品牌套件
- `Canva:list-brand-kits`。若有多个，询问是哪一个（或从团队/上下文推断）。
- 捕获套件暴露的任何内容（名称、缩略图，以及若存在的颜色/字体）。
- 应用上述数据缺口处理。若缺少作用域（例如“Missing scopes: [brandkit:read]”），告诉用户断开并重新连接 Canva 连接器以刷新令牌。

### 步骤 3：读取设计
- `Canva:get-design-thumbnail` 用于视觉/徽标/语气。
- 只读事务（开始 → 检查 → 取消）用于获取实际使用的颜色和字体。

### 步骤 4：对照品牌比较
检查每个维度并标记 **符合品牌 / 不符合品牌 / 无法核实**：

- **颜色**——填充/文本/强调色是否在品牌调色板内？标出不在调色板内的十六进制值（以及最接近的品牌颜色）。
- **排版**——字体是否匹配品牌字体？标出非品牌字体家族以及不一致的字号/字重用法。
- **徽标**——是否出现在预期之处、版本正确、未被拉伸/改色/拥挤（从缩略图视觉检查）。
- **语气与文案**——措辞是否匹配用户所描述的品牌声音？
- **一致性**——品牌应用是否在所有页面上一致？

每当套件未暴露数据且用户未提供时，诚实使用**无法核实**。

### 步骤 5：报告
```
## Brand check — "<design title>" vs "<brand kit name>"

Overall: ⚠️ Mostly on brand, 3 issues

### Off brand
- [Color] Page 2 heading is #1A73E8 — not in palette. Nearest brand color: #0B5CD7.
- [Font] Page 4 body uses Arial; brand body font is Inter.

### Can't verify (need input)
- Brand kit didn't expose hex values. Paste your palette + fonts for an exact check,
  or confirm the colors above against your guidelines.

### On brand
- Logo placement and cover treatment match the kit.
```

### 步骤 6：提议修复
提议通过 **`canva-edit-design`** 更正 API 可修复的问题——注意 API 可以更改**文本颜色**和字体**大小/字重/样式**，但无法更改字体**家族**或背景颜色（这些需在 Canva 中手动处理；见 `canva-edit-design`）。

## 规则
- 只读：检查后始终 `cancel-editing-transaction`。绝不提交。
- 绝不捏造品牌值——使用套件的真实数据或用户提供的内容，否则标记**无法核实**。
- 始终点明具体的页面/元素以及有问题的值 vs. 品牌值。
- 区分硬性违规（错误的徽标、不在调色板内的颜色）与软性问题（略微不一致的间距）。

# 演示文稿时间适配

取一份现有的 Canva 演示文稿，**仅使用演讲者备注**将其与目标演讲时长对齐。可见的**幻灯片文本会被读取**用于理解上下文和计时，但**不得**被此技能更改。流程是：确认**设计与总时长**（在克隆之前）、读取幻灯片文本、在幻灯片之间划分时间、为每张幻灯片**添加、替换或裁剪演讲者备注**以匹配各自的时间档、通过 Canva 编辑工具仅将**备注**写回。

## 主要工作流（时间均衡的演讲者备注）

### 步骤 1：收集设计与时长（在其他 Canva 工具调用之前）

- 在调用 `Canva:resize-design`、`Canva:get-design-content` 或其他编辑/内容工具**之前**，收集你所需的一切：
  - **设计**：链接（`canva.link`）、完整 Canva URL、**设计 ID**，或**设计名称**（各如何映射到 `design_id` 见步骤 2）
  - **总演讲时间**，用于交付该演示文稿（例如 `"15 minutes"`、`"45 min"`、`"1 hour"`）。解析为**总秒数**（或分钟的小数）。若用户含糊，确认他们想用于讲解幻灯片的总分钟数（仅在他们说明时才将问答包含在该总数内）
- 若设计或时长任一缺失，**先询问并等待**再继续

### 步骤 2：解析设计

- 若用户提供短链接（`canva.link`），调用 `Canva:resolve-shortlink` 获取设计 URL
- 若用户提供完整 Canva URL，提取设计 ID（`https://www.canva.com/design/{design_id}/...`）
- 若用户直接提供**设计 ID**（通常以 `D` 开头，例如 `DABcd1234ef`），将其作为 `design_id`；**不要**对原始 ID 使用 `Canva:search-designs`
- 若用户提供**设计名称**（非 ID），使用 `Canva:search-designs`；若有多个匹配，请其澄清
- 若仍无法解析设计，请其提供设计 ID 或链接

### 步骤 3：在副本上操作（必需）

- 使用 `Canva:resize-design` 以与源**相同的尺寸**克隆演示文稿；**不要**修改原始文件

### 步骤 4：读取幻灯片内容

- 在**副本**上调用 **`Canva:get-design-content`**，提取**每张幻灯片/页面的可见文本**（标题、要点、正文）
- 构建逐张幻灯片的摘要：幻灯片索引或标题、文本内容，以及若载荷包含演讲者备注则是否已存在
- **幻灯片数** = 此响应中带内容的页面数（用于步骤 5 的划分）

### 步骤 5：计算每张幻灯片的时间

- **每张幻灯片的目标演讲时间** = `total_duration ÷ number_of_slides`（除非用户要求对标题/结尾页加权不同，则调整并说明假设）
- 以约 **150 词/分钟** 为参考，推导每张幻灯片的**词数预算**：`target_words ≈ (target_minutes_per_slide) × 150`（合理取整；作为指导，而非硬性上限）
- 向用户展示一个小表格：幻灯片数、总时长、**每张幻灯片的秒数（或 mm:ss）**、每张幻灯片的大致词数预算

### 步骤 6：生成演讲者备注（在本次会话中）

- **直接在此响应中生成备注**；无需外部 API 调用。对**每张幻灯片**，使用该幻灯片在**步骤 4 中的文本**加上**步骤 5 中每张幻灯片的时间/词数预算**，撰写**演讲者备注**（这是你为计时唯一可以创作或编辑的内容）：
  - 力求在口头讲述时大致填满所分配的时间
  - 在**备注**中用上下文、过渡和表达提示扩展单薄的幻灯片；若预算较小则缩短**备注**（不要缩短幻灯片上的文本）
  - 忠于幻灯片可见的信息；不要臆造事实
- 若某张幻灯片**视觉密集**、文本很少，则撰写备注，描述在所分配时间内**围绕**该视觉要讲什么

### 步骤 7：将备注写回 Canva

- 在**副本**上调用 **`Canva:get-design-pages`**，获取每张需要备注的幻灯片的 **`page_id`**（或等价物）
- 若尚未激活，在副本上调用 **`Canva:start-editing-transaction`**；使用返回的 `transaction_id` 进行编辑
- **可选的顺序安排：** 在拿到副本的设计 ID 后**尽快**开始编辑事务（例如在步骤 4 之后或 `get-design-pages` 之后立即开始），以便在你花很长时间于聊天中撰写备注**之前**会话就已打开；在事务未被推迟时，某些环境超时的次数更少。若连接器允许整个流程使用**一个**长期事务，优先打开一次并复用 `transaction_id` 进行步骤 7 的编辑
- 调用 **`Canva:perform-editing-operations`**，**仅**使用 Canva MCP 为演讲者/演讲者备注暴露的**操作类型**（名称可能因连接器而异；使用**按页面**更新备注的 schema）。**不要**调用 `replace_text`、`find_and_replace_text` 或任何更改**幻灯片上可见文本**的操作。应用**所有**备注更新，在允许的情况下尽量合并为**少数**几次调用
- 调用 **`Canva:commit-editing-transaction`** 保存

### 步骤 8：交接

- 分享指向设计**副本的链接**，并用**一行**回顾：总目标时间和每张幻灯片的时间分配
- 提醒用户语速（约 150 词/分）因人而异，且**平均分配**是默认值；他们可在后续要求不同的加权

## 范围：仅备注

- **范围内**：通过 **`get-design-content`** 读取幻灯片文本。仅使用 MCP 的按页面备注操作，创建、更新、加长或缩短**演讲者/演讲者备注**。
- **范围外**：**不要**更改**可见的幻灯片内容**（`replace_text`、`find_and_replace_text`、格式、媒体、布局、标题等）。若用户要求删减或填充**幻灯片本身**，说明此技能仅调整**备注**；他们可以在 Canva 中编辑幻灯片或使用其他技能/工作流。
- **幻灯片数**：API 无法添加或删除页面。若时间目标对于幻灯片材料量不现实（例如从两张密集的幻灯片讲 60 分钟），请说明并建议**在编辑器中拆分或简化幻灯片**，或修订目标时长。你仍可撰写**承认**这一挤压的备注（例如“prioritise X, skim Y”），而不更改幻灯片文本。

## 当 `start-editing-transaction` 失败或超时

**原因（通常不是技能文本的问题）：** 当设计**较大**（页面/素材多）、**网络**缓慢或**服务器负载高**时，Canva 或 MCP 网关可能会以*“The operation was aborted due to timeout”***中止**。这是**基础设施/产品**限制，而非编辑 `SKILL.md` 能修复的东西。

**会话中该怎么做：**

1. 短暂停顿后（例如 15-30 秒）**重试一次** `Canva:start-editing-transaction`。瞬时失败往往在第二次尝试时成功。
2. 在流程中**更早地打开事务**（见步骤 7 的要点），以免聊天中漫长的备注生成过程夹在“准备编辑”与“启动事务”之间。
3. 若它**仍然**失败：明确告诉用户这是 **Canva/MCP 超时**，而非技能中的逻辑错误。建议他们**稍后重试**、按组织政策使用**稳定的网络/VPN**，或在演示文稿的**更小副本**（更少页面）上测试以确认流程可用。
4. **回退方案：** 将**生成的演讲者备注**粘贴到聊天中，**按幻灯片分组**（Slide 1: …、Slide 2: …），以便在自动化持续超时时用户可以在 Canva 的演讲者备注中**手动输入**。

## 规则

- 编辑前**始终**用 `Canva:resize-design`（相同尺寸）克隆
- 用 **`Canva:get-design-content`** **读取**；写备注前用 **`Canva:get-design-pages`** **解析页面 ID**
- **主要路径**：尽早确认时长 → 每张幻灯片预算 → 生成备注 → **仅备注的** `perform-editing-operations` → **提交**
- 此技能中**绝不**编辑幻灯片文本；**仅**编辑演讲者/演讲者备注（见**范围：仅备注**）
- 遇到 **`start-editing-transaction`** 超时：重试一次，然后解释并提供**手动备注回退方案**（见**当 `start-editing-transaction` 失败或超时**）
- 尽可能批量执行编辑操作

# Canva 课堂助手 — 教案转演示文稿

将教案转化为清晰、可教授的表达：学习目标上屏、逻辑流畅，并有幻灯片配套演讲者备注，使教师能用一份演示文稿上完整堂课。

## 工作流

1. **获取教案来源**（务必先做这件事——不要用替代性检查清单）
   - **不要**以一个笼统的两部分提示开场（例如“粘贴教案”*然后*“描述主题和要点”）。**教案**本身已携带主题和要点；问两遍是多余的，且跳过了本步骤真正的工作（文本 vs Canva 链接 vs 搜索）。
   - 若用户**尚未**给出任何来源，问**一个**仅匹配本步骤的简短问题，例如：*在此粘贴你的完整教案，**或**给出 Canva 设计链接或**设计 ID**，**或在 Canva 中搜索的确切标题**；若教案在文件中，粘贴内容或给出你能读取的路径。* 然后沿下方分支继续。
   - 若用户以**聊天中的文本**提供教案，则将其作为完整来源
   - 若用户直接提供 **Canva 设计 ID**（来自设计 URL 的标识符——通常以 `D` 开头，例如 `DABcd1234ef`），将该值作为 `design_id` 配合 `Canva:start-editing-transaction` 读取其文本内容（与从链接读取相同，无需解析 URL）
   - 若用户提供 **Canva 设计链接**（例如 `https://www.canva.com/design/DAG.../...`），从路径中提取设计 ID，并使用 `Canva:start-editing-transaction` 读取其文本内容
   - 若用户按名称引用 **Canva 文档或设计**，使用 `Canva:search-designs` 找到它，然后用 `Canva:start-editing-transaction` 读取其内容

2. **列出可用的品牌套件**
   - 调用 `Canva:list-brand-kits` 检索用户的品牌套件
   - 若只存在一个品牌套件，则自动使用它而无需询问
   - 若存在多个品牌套件，呈现选项并请用户选择一个（若相关，为学校或学区品牌）

3. **生成演示文稿**
   - 调用 `Canva:generate-design`，参数为：
     - `design_type`：“presentation”
     - `brand_kit_id`：所选的品牌套件 ID
     - `query`：遵循下方**教案 → 演示文稿查询格式**（始终是**多幻灯片**演示文稿——见该格式的开头几行）
   - 向用户展示生成的候选（按返回的缩略图/预览）

4. **完成**
   - 询问用户偏好哪个候选
   - 调用 `Canva:create-design-from-candidate` 创建可编辑的设计
   - 提供指向新演示文稿的链接，并用一行提醒幻灯片顺序与教学阶段的关系（例如“Opening → Instruction → Practice → Check → Close”）

## 教案 → 演示文稿查询格式

组织 `Canva:generate-design` 的 `query`，使 Canva 中的模型收到**教学法优先**的指令。此技能**仅**针对**多幻灯片演示文稿**（`design_type` 始终为 `"presentation"`）。以**一行**开启 `query`：**总幻灯片数**，以及输出必须是**标准多幻灯片演示文稿**（下方幻灯片计划中每项一张幻灯片）——绝不是海报、传单或单页布局。

包含以下章节（仅当教案确实没有该章节的数据时才省略）：

**课程简报**
- 科目 / 单元 / 年级（若缺失则从上下文推断）
- 课程标题和时长（例如 45 分钟、双课时）
- **学习目标**——学生将知道或能够做什么（提供时逐字取自教案）
- 标准（例如 CCSS、州或学区标准）——仅在用户提供时

**课堂弧线**
一段简短的话：课程如何为学生展开（例如 Engage → Explore → Explain → Elaborate → Evaluate；或 I Do / We Do / You Do）。尽可能匹配教案中教师的结构。

**幻灯片计划（教学演示文稿）**
对每张幻灯片，包含：
- 幻灯片 N — **标题原文**（简短，适当时面向学生）
- **教学目的**：一句话——这张幻灯片为课程做什么
- **幻灯片内容**：要点（3-6）——关键点、问题或提示；避免大段文字；使用适龄语言
- **视觉**：具体但**安全**的建议——优先照片、简单图标或抽象处理；见下方**视觉——它们从何而来**（避免要求生成器绘制密集标签、精细细节或图像内文字）
- **演讲者备注**：2-5 句——教师说什么、引导技巧、预期误解、快速理解检查、时间提示

**材料与后勤**（可选幻灯片或末尾附录幻灯片）
- 若教案中包含，列出材料、技术、分组和安全说明

**差异化 / 拓展**（若计划中有）
- 支持、挑战或作业的简要要点——可以是末尾一到两张专门幻灯片

## 教学法说明

- **尊重教案**：优先采用作者的顺序、词汇和活动；仅为清晰或幻灯片数量限制而重组，并保持目标与来源一致
- **尽可能每张幻灯片一个核心想法**；将密集步骤拆分到多张幻灯片
- **适龄**：根据所述或推断的年级调整阅读水平和示例
- **稀疏的教案**：若教案较薄，用标准课程结构（目标、直接教学、练习、评估、收尾）扩展，并在生成前后向用户简要说明假设

## 视觉——它们从何而来以及如何避免糟糕的图像


**为什么自动化视觉常常偏离课程**
在**任何科目**（读写、历史、STEM、艺术、SEL 等）中，AI 辅助和自动挑选的图像在以下方面**不可靠**：图片**内**可读的文字；确切事实（日期、名称、引述、词汇）；必须精确的地图、时间线或图表；必须与来源材料相符的人物、地点或事件描绘；以及任何**正确措辞**对评估或标准对齐很重要的幻灯片。模型可能混淆语言、混用语言、臆造标签，或选择**看似合理但错误**的图像。

**在 `query` 中放入什么（缓解措施——任何教案）**
在生成查询开头附近包含明确的**全局视觉规则**，例如：
- 优先**简单照片、纹理、图标或抽象背景**；避免要求生成器在图像本身中使用**密集信息图、带标签的插画或“大量文字的 poster”**。
- **不要依赖图像中烘焙的文字**——说明关键术语、定义、问题、数字以及**所有对课程至关重要的措辞**应放在**幻灯片文本**中（以课程语言，通常为英语），而不是图片内。
- 对于**准确性至关重要**的幻灯片（词汇、时间线、流程、数据、原始资料、艺术作品标题等）：要求**极简或装饰性图像**，并将正确内容放入要点/标题；提醒教师也必须**核实**幻灯片文本。
- 可选地要求整体**少图或干净模板**的感觉，以便教育工作者在生成后替换为经过审核的**元素**、上传内容，或来自可信来源的截图。

**演示文稿生成之后**
建议在 **Canva 编辑器中完整过一遍**：替换误导性图像、修正幻灯片文案、添加或粘贴经审核的媒体。编辑 API（`perform-editing-operations` 等）可在后续工作流中协助处理文字和部分媒体——参见 `implement-feedback` 模式——但**忠于课程**的视觉和措辞最终需要**人工审核**。

**交接时设定预期**
简要警告**自动生成的课程视觉是草稿**，不保证对任何主题都准确——教师应将其视为**未经验证**，直至审核。

## 说明

- 与品牌演示文稿技能相同的工具链：品牌套件 + `generate-design` + `create-design-from-candidate`
- **自动填充**和高级生成功能可能需要 **Canva Enterprise** 套餐——若工具报错，简要说明并建议在 Canva 中手动编辑

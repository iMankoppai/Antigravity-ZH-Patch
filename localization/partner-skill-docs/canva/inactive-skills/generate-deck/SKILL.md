# Canva 演示文稿构建器

使用 Canva 应用借助 Canva AI 生成演示文稿类型的设计，尤其是品牌营销演示文稿和销售演示文稿。即使生成工具可以创建许多其他设计类型，也要将工作流聚焦于多幻灯片演示文稿。

## 核心规则

对于演示文稿请求，直接调用 Canva 应用 `generate-design` 工具，`design_type: "presentation"` 并使用演示文稿特定内容。若应用暴露可调用名称，这意味着使用 `_generate_design`，而非 `_prepare_design_generation`。切勿为此技能使用 `prepare-design-generation`、`_prepare_design_generation` 或大纲审核辅助工具。不要使用 `doc`、`document`、`proposal`、`report`、`infographic`、海报、社交帖子或其他设计类型。若用户明确切换到演示文稿之外，改用不同的工作流，而非此技能。

此技能的要点是：在使用宽泛的设计生成工具时，让 Canva AI 的生成保持演示文稿形态。始终在 `generate-design` 的 `query` 中提供足够的演示文稿特定上下文，使其不会产出文档式或单页的结果。若没有 prepare-design-generation 步骤就无法直接生成，请停下来告诉用户，而不是调用 prepare 工具。

## 演示文稿聚焦

针对营销和销售成果优化演示文稿：

- 受众：买家、潜在客户、客户、合作伙伴或内部市场进入利益相关者。
- 目的：定位品牌或产品、传达价值、支持活动、赋能销售、推介报价，或推动下一步。
- 内容形态：简洁信息、清晰定位、具体收益、证据点，以及明确的行动号召。

优先采用有说服力的商业叙事，而非通用的信息性大纲。有用的弧线包括：

- 问题 -> 洞察 -> 解决方案 -> 价值 -> 证明 -> 下一步。
- 市场转变 -> 客户需求 -> 产品故事 -> 差异化 -> 成果 -> CTA。
- 受众痛点 -> 期望结果 -> 报价 -> 能力 -> 可信度 -> 购买路径。



## 输入

将用户的简报、大纲、笔记或粘贴的内容作为来源材料。若缺少重要的演示文稿参数，推断合理的默认值，而不是阻塞：

- 受众：从简报推断，或使用通用的专业受众。
- 长度：从内容推断；对于普通初稿，目标 8-12 张幻灯片。
- 语气：匹配用户的语言；默认为清晰、精炼且有用。
- 目标：推导预期的商业成果，例如激发兴趣、说服买家、推介产品、赋能销售、回顾活动，或对齐市场进入团队。

仅在缺失的选择会实质性改变演示文稿时才追问，例如演示文稿是针对高管还是客户，或用户是否需要非常具体的幻灯片数量。品牌套件选择是例外：生成前始终请用户从可用品牌套件中选择。

## 品牌套件处理

对每个演示文稿请求：

- 调用 Canva `list_brand_kits`（使用可调用名称时为 `_list_brand_kits`）以找到可用的品牌套件。
- 向用户建议可用的品牌套件，并请他们在生成前选择一个。
- 不要自动选择品牌套件，即使只有一个套件可用或某个套件看起来明显相关。
- 调用 `generate-design` 时，将所选套件作为 `brand_kit_id` 传入。
- 若没有可用品牌套件，说明未找到，并询问是否在没有品牌套件的情况下继续。
- 若 `list_brand_kits` 报告缺少 `brandkit:read` 作用域，请用户断开并重新连接 Canva 应用后再继续。
- 若用户明确选择在没有品牌套件的情况下继续，则使用所提供的公司、产品、语气、颜色或信息，保持演示文稿的品牌感知，而不臆造品牌规则。

此技能中不要使用 Canva 模板工具，包括 `search-brand-templates`、`get-brand-template-dataset`、`autofill-design` 或 `create-design-from-brand-template`。若用户要求使用、搜索、以模板开始或自动填充模板，说明此技能仅使用品牌套件配合直接 `generate-design`，并询问他们是想在没有模板的情况下继续，还是切换到不同的 Canva 模板工作流。

## 生成提示词

将生成提示词写成演示文稿简报，而非通用的文档提示。包含：

- 工作标题。
- 受众和目标。
- 期望的幻灯片数量或范围。
- 叙事弧线。
- 品牌、产品、报价、品类和定位。
- 主要客户痛点和期望结果。
- 关键价值主张、差异化和证据点。
- 逐张幻灯片的大纲，并附具体幻灯片标题。
- 每张幻灯片的关键要点或发言要点。
- 每张幻灯片的视觉方向，例如图表、时间线、对比表、产品截图、示意图或图像主题。
- 有用时的演讲者备注指导。
- 用户提供的任何品牌、语气或格式限制。

优先采用具体、以成果为导向的幻灯片标题，而非含糊的章节标签。使幻灯片便于扫读且视觉化；避免密集散文、文章式章节或报告式的页面结构。

对于销售演示文稿，包含可能的买家问题、方案契合度、收益、可信度、顾及异议的证明，以及下一步。对于营销演示文稿，包含活动或品牌背景、目标受众、信息层级、报价、相关时的渠道或用例，以及令人难忘的 CTA。

## 候选定稿

若 Canva AI 返回设计候选，向用户呈现候选并询问他们想将哪一个转为可编辑设计。选择后，使用 Canva 的从候选创建流程，并返回最终的 Canva 设计链接。

## 边界

仅将此技能用于通过 `list_brand_kits`、直接 `generate-design` 和从候选创建来创建新的 Canva AI 演示文稿草稿。对于编辑现有 Canva 设计、落实审阅者反馈、翻译、调整尺寸、品牌检查、prepare-design-generation 或基于模板的生成，请使用针对该任务的更具体的 Canva 技能或应用工作流。

# 编辑 WordPress 区块内容

## 了解站点上下文

- 当目标站点和 WordPress.com MCP 服务器可用时，在创建或编辑内容之前调用 `wpcom-mcp-site-editor-context`，查明有哪些可用的区块类型。
- 在为内容设置样式时，使用同一工具获取当前主题预设和样式。在支持的区块属性中，优先使用返回的主题令牌，而非硬编码值或自定义样式设置；仅当主题和区块属性无法实现所需结果时，才使用自定义样式。
- 如果目标站点或 WordPress.com MCP 服务器不可用，则新内容仅限于核心区块和所提供内容中已存在的自定义区块。

## 要求

- 你必须保持内容在区块编辑器或站点编辑器中可编辑，这要求仅使用已注册的核心区块或现有的插件区块。
- 不要在区块分隔符之外添加装饰性的 HTML 注释。
- 除非请求明确要求更改，否则保留不熟悉的自定义区块、动态区块、引用、属性、类和内部标记。
- 保持区块属性与已保存标记一致。不要臆造媒体 ID、URL、可复用区块引用或自定义区块属性。

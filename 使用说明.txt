Antigravity 中文补丁 v26.1 修订版 —— 跨电脑使用说明
适配版本：Antigravity 2.18.1
打包日期：2026 年 10 月 1 日

一、先了解这份压缩包

这是汉化补丁，不包含 Antigravity 软件本体。另一台电脑需要先安装 Antigravity 2.18.1。
本包适用于 Windows x64 电脑，不适用于 macOS 或 Linux；其他应用版本、ARM 电脑没有完成验证。
已经附带 Node.js 24.21.0 运行环境，不需要另外安装 Node.js、npm 或 PowerShell 7，也不需要联网下载依赖。
安装时会选择另一台电脑自己的软件位置，不要求安装在 D 盘，也不要求使用相同的用户名。

二、另一台电脑怎么安装（按顺序做）

1. 把完整的 ZIP 压缩包复制到另一台电脑。
2. 右键压缩包，选择“全部提取”，完整解压到一个准备长期保留的文件夹。
   例如：D:\Tools\Antigravity-ZH-v26-Windows-x64
   不要直接在压缩包里运行，也不要只取出某个文件。
3. 完全退出已经打开的 Antigravity。如果托盘里还有它的图标，也要退出。
4. 双击解压文件夹里的“安装汉化.cmd”。
5. 在弹出的选择窗口中，找到这台电脑上的 Antigravity.exe，选择并打开。
   常见位置包括：
   - D:\Antigravity\Antigravity.exe
   - C:\Users\你的用户名\AppData\Local\Programs\Antigravity\Antigravity.exe
   - C:\Program Files\Antigravity\Antigravity.exe
   也可以先右键软件原来的快捷方式，查看它的目标或“打开文件所在的位置”。
6. 看到“安装完成”后，双击桌面新建的“Antigravity 中文版 v26”启动。
   如果没有看到桌面入口，也可以双击解压文件夹里的“启动中文版.cmd”。

原来的软件快捷方式不会被覆盖，开机启动项也不会被修改。
请保留整个解压文件夹：桌面中文快捷方式和运行环境都引用这里的文件。

三、平时怎么使用

以后通过“Antigravity 中文版 v26”或“启动中文版.cmd”打开。
首次启动会稍等片刻，页面汉化完成后出现“中文补丁已加载”提示。
这个提示几秒后自动消失，补丁仍然在运行。

如果先通过软件原来的英文入口打开，需要完全退出后再从中文入口启动。
不要同时运行两份不同文件夹中的汉化补丁。

三点一、从旧版升级

完全退出 Antigravity（包括托盘），先运行旧补丁文件夹里的“恢复英文.cmd”，再按第二节安装完整的新包。
不要同时运行不同目录的两份补丁，也不要用新文件覆盖旧版恢复备份。
本修订版的桌面入口名称仍为“Antigravity 中文版 v26”。

四、这版包含哪些功能

- v26.1 修复归档提示、对话不可用和文件夹空状态。
- 补齐等待登录与验证成功、数据使用说明、首次主题选择、插件介绍、权限与沙盒提示、项目教程的漏翻。
- 长句分批显示时也会完整翻译；“创建项目”教程中的英文演示使用中文步骤示意，保留原有操作按钮。
- 84 项浏览器回归检查和 9 项隔离安装与恢复检查通过；登录相关文字按真实结构模拟验证。
- 1462 个词条：设置、历史、定时任务、插件和 MCP 目录、文件审阅、命令面板等主要界面。
- 浅色与深色预设的 9 个主题名称显示中文，鼠标悬停显示英文原名；主题本身与选择不变。
- 概览栏目、文件差异菜单、预览与评论提示、技能命令说明和空结果、项目设置以及定时任务表单已补齐中文；任务时间使用 24 小时显示。
- MCP 目录本次收录的 98 条服务说明中文化；服务名称保留原名。
- 按场景处理 Type、Plan 等词语，避免“输入”和“类型”、“规划”和“订阅方案”混淆。
- 词典分类和热更新：修改词典后，打开的页面自动更新；JSON 写错时继续沿用上一份有效词典。
- 页面文字分批处理，新增界面内容自动汉化。
- 保护对话正文、Markdown 文档正文、输入文字、对话与项目名称、代码、命令、文件路径及终端输出。
- 切换设置页回到顶部；命令面板中文前缀保持单行。
- 对匹配的原生文件夹选择窗口标题进行中文适配，并保留本机恢复备份。

英文对话标题、产品或服务名称、代码、路径、键名及内嵌成果中的英文通常属于原始内容，不代表补丁失效。
已实际检查新建项目、项目设置与删除确认框、文件搜索、图片加载失败、评论表单、斜杠技能菜单及定时任务表单；没有提交评论、创建定时任务或删除项目；另经用户确认发送了一条只回复文字的测试消息。
当前应用未启用 PDF 和笔记本渲染，只能查看原始内容；补丁不会开启这些功能。登录、许可证、安装进度与配置失败、PDF 和笔记本错误提示已通过源码检查及不联网的模拟页面验证；已完成一次只回复文字的真实任务测试，并补齐运行状态漏翻；真实登录、插件安装及涉及工具执行的任务状态仍未实测。

五、原生窗口标题是怎么处理的

安装工具只对匹配已验证版本的应用资源进行适配：
Open workspace -> 打开工作区
Open workspaces -> 选择多个工作区

会先备份这台电脑原来的资源，再改动 resources\app.asar 中的两个标题。
不修改 Antigravity.exe 或 language_server.exe。
原生备份保存在解压文件夹的 backups 中，不是从发送者电脑复制过来的。

如果应用版本、资源校验或权限不匹配，工具会跳过原生标题适配，页面汉化仍可使用。
安装目录受保护时，原生适配可能需要对该目录的写入权限；可使用同一个 Windows 账号以管理员身份运行安装入口。
软件升级后，原生修复可能被覆盖。此包会阻止把旧版备份覆盖到已改变的应用资源。

六、怎样恢复英文或停用

1. 完全退出 Antigravity，包括托盘中的程序。
2. 双击本文件夹里的“恢复英文.cmd”。
3. 它会停用这份补丁、结束这份补丁的后台进程、移除它自己创建的桌面入口。
4. 如果本包曾修改原生资源，且应用仍与校验版本一致，会恢复这台电脑自己的原生备份。
5. 以后从软件原来的快捷方式启动即可。

其他用途的 Node.js 进程和原来的快捷方式不会被处理。
文件夹与备份会保留。确认恢复成功后，如果不再使用，可以手动删除整个解压文件夹。
如果提示“应用已更新”，原生资源不会被旧备份覆盖；页面补丁仍会停用。
需要重新启用时，再次运行“安装汉化.cmd”。

七、常见问题

问：另一台电脑不是装在 D 盘，能用吗？
答：能。安装时选择实际的 Antigravity.exe 即可。

问：软件升级到其他版本了，能直接安装吗？
答：这份定版只验证了 2.18.1。安装器会提示版本不匹配并停止，需要针对新版本重新检查。

问：一直显示英文，怎么办？
答：先完全退出，再用中文入口启动；确认整个文件夹已完整解压。
    若仍失败，查看同文件夹中的 launcher-error.log 和 injector.log。

问：提示 19229 或 9229 端口被占用？
答：检查是否还有另一份汉化补丁或 Antigravity 在运行，关闭冲突的那一份再重试。
    不要直接结束所有 node.exe，它们可能属于其他软件。

问：解压文件夹移动后快捷方式打不开？
答：先完全退出软件，移除桌面旧的“Antigravity 中文版 v26”快捷方式，再在新文件夹里运行“安装汉化.cmd”。
    这样会重新生成指向新目录的中文入口；不要删除原来的软件快捷方式。

问：可以改翻译吗？
答：可以编辑 dictionaries 里的 JSON 词典。修改前先备份；保存有效的 JSON 后自动更新页面。
    修改 translate.js、injector.js 等程序文件后需重启补丁后台，建议日常使用保持定版不改。
    安装入口会核对发布文件；已自行修改文件时，再次安装可能提示校验不一致。

# v64：Antigravity 2.25.0 适配与原生菜单补全

日期：2026-10-22。本地修复，管理器版本仍为 1.2.0，汉化内核升至 v64。GitHub 已发布的 v1.2.0 安装包仍是旧内核。

## 截图问题及根因

四张截图均涉及 Electron 原生右键菜单。它们通过 `electronNative.showContextMenu` 发送给主进程，再由 `buildContextMenuTemplate` 构建，网页 DOM 翻译无法覆盖。除“复制项目名称”等缺少词条的动态组合外，大部分英文在词库中已有中文，但此前没有接入原生菜单。

现在在原生菜单构建的普通项目和子菜单两个分支翻译标签，因此同时覆盖：

- 项目菜单：复制项目名称、项目设置、在文件资源管理器中显示、删除项目。
- 对话菜单：重命名、置顶、已读／未读、复制、分屏、归档、恢复、永久删除等。
- 复制子菜单：对话名称、对话 ID、工作区名称、项目名称。
- 分屏子菜单：向右分屏、向下分屏、替换为新对话、从分屏中移除。
- 同类入口：单项复制菜单、分组排序、标签页关闭、图片复制及窗口操作。

只翻译已复核的固定菜单标签，用户自定义分组、未知标签、模型名、路径保持原样。原始命令 ID、点击回调、快捷键、勾选／禁用状态、分隔符及关闭菜单的逻辑保持不变。没有全局改写 Electron Menu，避免破坏应用依赖英文标签查找菜单的行为。

原生菜单修复需要退出客户端后重新永久安装；仅“开启汉化”的网页热加载不足以更新已运行的主进程菜单代码。

## 2.25.0 新版排查

读取本机 2.25.0 官方归档，并与保存的 2.24.0 原版逐模块比较。原生 JavaScript 模块中只有 `dist/main.js` 内容变化；原有安装挂点仍匹配，菜单两个标签挂点均命中。新版原版归档 SHA256：`ad7fb1a177a11522490cba910c0970a117bec568cd9ad85233fa62873361ed05`。

前端使用本机更新后缓存中提取的最新 bundle（10,178,381 字节），随后通过当前客户端的本地 HTTP 服务核对 SHA256 完全一致，再与旧版 10,095,222 字节资源比较；静态扫描覆盖 27 份前端及原生源码，提取并检查 3,270 个去重的界面候选。候选包括 CSS、内部标识和待实例化的模板，因此不能把候选数当作漏译数。

新增与补全内容包括多账号默认账号、账号数量、登录说明、语音启动／结束／静音及错误提示、插件侧栏显隐、MCP 应用侧边面板、执行身份、发布通道及版本提示、磁盘已满提示。还补上旧版拆分节点中的侧边面板介绍、邮件订阅说明与发送状态。

词库由 5,638 条增至 5,693 条，另增加默认账号和账号数量两类动态模板。默认账号中的邮箱与提供商保留原样；MCP 加载提示只翻译固定前缀，应用标题和诊断信息保留原样。`a2a (ttv2)`、地址示例和程序内部标识有意保留。

基线生成器同时补记可选的 WSL 准备窗口哈希，修复未来兼容版本检查缺少这一模块依据的问题。

## 验证与交付

新增原生菜单回归与 2.25.0 网页回归，均接入 `scripts/check-current.ps1`。原生集成回归直接执行生产安装器产出的归档中菜单构建函数，验证嵌套菜单、点击返回 ID、快捷键、禁用／勾选状态以及自定义名称保护。网页回归覆盖新增文案、动态更新、邮箱／模型／用户内容保护和精确还原。

使用真实 2.25.0 原版的隔离副本执行安装、重复安装、英文还原，验证还原后的字节与原版完全一致；原件备份与新安装归档分开核验。完整检查记录保存在 `work/localization-v64/`。

完整统一检查 28 项通过，失败 0、跳过 0；原生菜单集成回归 57 项、新版网页回归 65 项，兼容修复回归 41 项通过。发布构建内的运行时、词库、技能目录、生成内核与基线清单均逐字节匹配源码。

本地统一保留 `Antigravity汉化管理器.exe`，其内核为 v64；带 v63、v64 后缀的旧版／重复程序已按用户要求清理。真实窗口先完成热加载并验证 v64；用户确认退出后，生产安装器已完成本机 2.25.0 永久安装，并建立同版本原件备份。实际安装归档与隔离验证归档逐字节一致，内嵌 bundle 与源码一致；直接针对真实安装归档运行的原生菜单 57 项集成回归通过。重新打开客户端后加载新菜单；本轮未主动重新启动客户端进行现场 UI 验收。

本轮不宣称任意插件远端页面、任意动态错误或用户生成内容都已翻译。现有官方插件与技能正文继续通过原有结构和还原回归；实际新通知、需登录的多账号状态与语音通话仍需相应场景触发后验收。

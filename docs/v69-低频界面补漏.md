# v69 低频界面补漏

适配 Antigravity 2.26.0（Windows x64）。管理器版本继续为 1.2.0，汉化内核升级为 v69，主词库为 5,894 条。本次为本地构建，未上传 GitHub。

## 排查方法（work/audit-v68-fresh/）

1. 从 Chromium 缓存解码 2.26.0 现役前端 bundle（10,461,461 字节，9/9 界面标记命中），并保留 7 份历史版本 bundle 作差分基线。
2. 抽取 37,201 条字符串字面量，UI 形状过滤后得 2,491 条候选（词库精确键已剔除 2,375 条）。
3. 候选灌入无头 Chrome 运行真实 `translate.js`：2,475 条未被引擎翻译，即词库外字符串全集。
4. 按锚点排除 ELK/Monaco/Lexical/KaTeX/PDF.js 等库数据区（554 条），再做版本差分：2.26.0 新增 UI 字符串 778 条中，词库与 v68 审计未覆盖的仅 28 条，逐条复核均为内部诊断串或 CSS 类名。
5. CDP 只读扫描运行中客户端当前画面（含隐藏元素与 aria/title/placeholder 属性），排除对话正文保护区。

结论：2.26.0 新增界面覆盖完整（版本差分零缺口）；实机确认 1 条真漏译与一批低频缺口候选。

## 修复内容

- **实机确认漏译**：`File exceeds the {0} display limit ({1}).` ➔ `文件超过 {0} 的展示限制（实际 {1}）。`（新增动态模板，双数字占位）。
- **新增 20 条词条**：
  - 输入框占位符短变体 `Ask anything, @ to mention`（非 workflow 模式使用，词库原只有长变体）；
  - 表单校验 `Name is required`、`Name must be folder-safe (…)`；
  - 消息还原 `Cannot revert this message`（词库已有同族其余句式）；
  - VCS 标签 `Working copy`、按钮 `Create a JJ worktree`；
  - 网页读取状态 `Reading page` / `Read page`；
  - 书签操作状态族 `Bookmarking` / `Bookmarked` / `Removing bookmark` / `Removed bookmark` / `Canceled bookmark of` / `Canceled removal of bookmark` / `Canceled creation of` / `Canceled deletion of`；
  - 执行环境加载 `Loading harnesses…` / `Couldn't load harnesses.`（跟随同对话框既有的"实验配置"译法）。
- **状态前缀白名单扩展**：`(?:Auto-)?proceeded with`、`(?:reading|read) page` 与书签族加入 `translateStatusLabel` 白名单（配合词库键命中）。

## 判定依据与撤案记录

- `Zoom to Fit` 经上下文核实属于 ELK 布局库选项描述，非界面按钮，撤案。
- `Starting search` / `Search complete` 为 `debug()` 日志串，不上屏，撤案。
- `Not found` / `Invalid date` / `Deadline exceeded` 等为 gRPC 状态名映射与 zod 校验串，按保留策略不译。
- 上下文核实后确认已覆盖：`Message subagent, @ to mention`、`Create a Fig shared workspace`、`Undo to this point`、`Created outline`、`Runs even when…` 组合句等，避免重复添加。

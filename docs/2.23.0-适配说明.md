# Antigravity 2.23.0 适配说明（v1.0.2）

发布日期：2026-10-13。**本版本适配 Google Antigravity 2.23.0（Windows x64）**，汉化内核 **v39**，词条 **3,497 条**。

## 为什么 2.23.0 需要重新适配

官方 2.23.0 更新会整体替换 `resources/app.asar`，内嵌的汉化内核随之被覆盖；而且**这一版界面层确有改动**，不能靠旧内核直接沿用：

| 比对项 | 2.21.1 / 2.22.0 | 2.23.0 |
| --- | --- | --- |
| 前端 bundle 大小 | 9,607,177 字节（两版逐字节相同） | **9,902,207 字节** |
| 新增可读字符串 | — | 437 条（其中界面文案候选 142 条） |
| 主进程 5 个注入锚点 | 各命中 1 次 | 各命中 1 次（结构未变） |
| 安装目录 | 曾为 `D:\Antigravity` | 官方又改回默认 `%LOCALAPPDATA%\Programs\antigravity` |

## 本轮内容

| 项 | 变化 |
| --- | --- |
| 汉化内核 | v37 → **v39** |
| 词条数 | 3,361 → **3,497** |
| 新增覆盖 | 137 条界面词条：插件包（Bundles）、Google Drive 连接与上传、SSO / 企业账号登录、会话已读与未读标记、权限详情、排序与最近使用、Zip 附件、音量与播放、文件夹校验提示、新引导页文案等 |
| 修复误译 | 模型名不再被逐词翻译（`Gemini 3.8 Flash High` 曾渲染为 `Gemini 3.8 Flash 高`，与同一按钮的无障碍标签自相矛盾）；模型名与推理档位选项统一保持英文 |
| 修复死词条 | 清理 6 条键里带前后空格、永远无法命中的词条（运行时查表前会 `trim`） |
| 补齐模板 | 权限预设按钮的 `aria-label` 与悬浮提示两条动态模板规则 |
| 选择器修复 | 会话行标题保护改为前缀匹配（官方 testid 是动态的 `conversation-row-${kind}`） |

## 验证

- 统一门禁 **17 项全部通过**（词库质量、正则安全、内核同步、生成器确定性、渲染回归、打包/版本/基线三方一致、真实安装演习、引擎基线）。
- 渲染回归断言 **73 → 80 条**，新增用例锁定“模型名与档位保持英文、面板其他文案仍汉化”的边界。
- 真实客户端安装与现场复核：内核 v39 / 3,497 条生效，`lang=zh-CN`，界面文案为中文，侧边栏对话标题等内容保持原文。
- 三方一致：源码 `zh-bundle.js` = 临时产物 = 已安装归档内内核（逐字节相同）。
- 官方原版备份 `resources/app.asar.bak` 在首次安装时自动生成，可随时一键还原英文。

## 使用提示

1. 官方每次大版本更新都会覆盖补丁，更新客户端后**重新执行一次【永久安装汉化】**即可（管理器会自动识别新版本并校验归档与备份）。
2. 若官方换过安装目录（例如从默认目录改到其他盘），管理器会自动探测；也可在界面中手动指定 `Antigravity.exe`。
3. 界面里仍会看到英文的地方分两类：**内容**（AI 正文、你的输入、项目名、服务端公告）与**专名**（模型名、主题名、快捷键）——这些按设计保留原文，判断方法见 `docs/汉化范围说明-哪些不翻译.md`。

## 已知边界

- 模型列表里的 `Notice` / `NEW` 徽标由服务端模型配置下发，属内容，不翻译。
- 权限申请、沙箱警告、上下文压缩、分支/分享等深层场景已纳入自动化文字覆盖检查，但真实触发需要在客户端内人工验收。

# 新版汉化适配

Antigravity 更新后，如果界面变回英文，打开汉化管理器，点击右上角【新版汉化适配】（位于【检查更新】旁边）。

- 客户端正在运行：先核验版本兼容性，通过后恢复当前窗口中文，保留会话与输入内容。
- 需要永久汉化：彻底退出 Antigravity，包括客户端托盘，再次点击【新版汉化适配】。安装完成后，重新启动客户端即可。
- 已安装当前版本的汉化时，提示已就绪，不重复写入。
- 更新尚未完成、文件被占用或版本不兼容时，显示原因，用户处理后再次点击。

管理器没有后台升级监测、定时检查、自动重试或退出客户端后自动安装。无需为了更新后恢复汉化而让管理器常驻；关闭到托盘仅方便再次打开。手动恢复英文后，不会被后台操作再次切回中文。

## 兼容范围

已登记的官方版本要求归档 SHA256 与登记值一致。未登记的更高补丁版本，须与参考版本的主、次版本相同，且软件名称、入口、依赖声明与五个目标模块（`ipcHandlers.js`、`main.js`、`utils.js`、`tray.js`、`wizard.js`）完全匹配。

当前参考为已验证的 Antigravity 2.23.1。跨系列版本、原生模块或依赖变化、损坏的归档不会强制套用补丁，需要后续适配。兼容核验不代表未来版本所有新增文案都已有翻译。

## 备份与恢复

永久安装使用 `resources/app.asar.bak` 保存本版原件。另一版本的旧备份先保存为 `app.asar.bak.<版本>.<SHA256>`，再建立新版备份。安装记录包含原件版本和哈希，还原时核对对应原件，避免把旧版文件写回新版。

写入前、提交前再次检查客户端运行状态和资源哈希，并校验临时包及最终归档。手动适配、永久安装和英文还原共用操作锁。

选定路径和客户端托盘选项保存在 `%LOCALAPPDATA%\AntigravityZhManager\settings.json`。旧设置中的自动恢复字段被忽略。

## 3.1 计划编辑器结构适配（2.29.0 新增）

旧版用 `[data-testid="schedule-frequency-trigger"]` 的 `data-frequency` 判断计划频率；2.29.0 改为 `[data-testid="schedule-repeat"]` 下拉（当前选项写在触发按钮首个 `<span>` 里，如 `Custom` / `Every day`）。已把 `translateScheduledText` 的 `on` 连接词判断改为两种结构兼容：custom → “规则”，其余 → “在”；并补 `hours`/`week`/`month` 三个单位词条。新增渲染回归 `tests/renderer/schedule-summary-regression.cjs`（8 项，已并入统一门禁）。

# v1.1.4 技能详情排版与段落翻译

日期：2026-10-19（北京时间）。适配 Antigravity 2.24.0 Windows x64，管理器 v1.1.4，内核 v59。

v58 的正文验收不足：逐文字节点翻译虽然可以保证节点数量不变，却无法保证句子连贯；保持原始结构，也保留了原文中已经损坏的表格。此前“982 项通过”不能证明这些详情的排版和译文质量已经合格。

本轮重新检查 17 个官方插件、140 份 SKILL.md 的正文。13 份文档存在 250 行非标准的冒号表格续行，现将其合并到对应行和单元格后再渲染。Google Slides 批量操作表恢复为 27 条操作，“Op”“Key Fields”分别校订为“操作”“关键字段”。尖括号占位符、包含反引号的示例，以及没有正确形成代码块的 CLI 帮助文本，也在展示副本中整理。原始技能文件没有修改。

正文改为 8,966 个完整段落、列表内联段或表格单元格的翻译目录，不再在运行时逐文字片段拼接。批量初稿使用完整上下文，技术文档中的 cell 与生物学文档区分处理，prompt 的动词用法不强制替换为“提示词”。124 个段落或单元格另行校订；Google Antigravity SDK 沿用上一轮人工校对内容。53 个产品、语言、数据库标识或参数按保留清单处理。常见数学标记改为可直接阅读的符号或上下标。

显示时保留 React 管理的原始正文节点，另行展示本地化正文；原始节点不被替换或删除。译文中的链接委派给原链接事件处理器，代码块提供复制按钮。支持动态打开、切换文档、热更新目录、清理已关闭的文档和精确英文还原。未知文档及用户、智能体的会话正文不使用这个目录。

验证覆盖全部 140 份正文的代码、链接、列表、表格实际行列与英文还原，额外测试代码复制、链接事件、动态切换和重复热加载。离线逐份渲染审计检查 50 张表格，并为需要整理表格的 13 份文档生成预览。自动化检查能够验证结构、完整性和已知误译，不能证明 8,966 个段落全部逐句人工精校；批量译文仍可能需要后续用语修订。

构建过程完全离线。正文目录由 `scripts/build-skill-detail-views.cjs` 读取本地的段落、译文和已校对 SDK 资料组装，内核通过统一生成器嵌入管理器与永久补丁。软件使用期间不调用在线翻译服务。深层 references/examples 文件仍作为引用路径保留，不属于本轮正文翻译范围。

本轮证据、实际生效状态及预览位于 `work/skill-detail-v59/`；本地交付，未上传 GitHub。

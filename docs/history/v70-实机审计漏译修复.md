## 修复内容

### F1 会话列表相对时间

- **现象**：侧栏与历史页会话行时间 `3m / 18m / 2h / 13d` 原样显示；会话头部的"3 分钟前"正常。
- **根因**（两层）：① `translatePlatformUi` 的相对时间规则要求 `nav[aria-label="Sidebar"]` 且不在链接内——2.26.0 侧栏地标变更、行改为链接结构、历史页行为新增界面，三重失配；② `shouldSkipTextNode` 的 `identitySelector`（`a[href^="/c/"]`）把整个会话行子树当会话名跳过。
- **修复**：规则上下文扩展到 `[data-testid="conversation-row-sidebar"], [data-testid="conversation-row-history"]`；`shouldSkipTextNode` 为带 `opacity-60.min-w-4` 类名特征的时间 span 放行。恰好形如时间的会话名（无该类名特征）保持受保护。

### F2 历史页归档横幅尾节点

- **现象**：横幅显示 `在侧边栏查看已归档项 (⌘ menu).`——头节点已译、`(⌘ menu` 与 `).` 生肉。
- **根因**：该句在横幅中的节点切分为 `["View archived in the sidebar ", "(", " menu)", "."]`（筛选图标夹在括号与 menu 之间），容器不是 toast——`translateArchivedNotification` 在 toast 容器守卫处即返回。头节点另被词典键 `View archived in the sidebar` 直翻，导致 v40 的整句英文正则永远失配。
- **修复**：为非 toast 容器新增横幅分支——从所在 span 向上寻找能以 `originalText` 拼出整句的容器，按节点内容分派改写（兼容 Toast 与横幅两种切分，未知片段保持原样）。

### F3 软导航后 aria-label 漏翻

- **现象**：SPA 内部路由到达的页面（如项目新对话页）上，输入框工具条的 `Send message`、`Select model, current: …`、`Select Environment`、可见文本 `Local` 等长时间生肉；硬刷新自愈。
- **根因**：路由软切换后挂载的属性批次错过观察器首轮入队，之后无新 aria 变更触发补翻（实机探针证明该页翻译管道正常）。
- **修复**：钩住 `history.pushState/replaceState` 与 `popstate`，各安排 120ms+600ms 两次全根补扫；沙箱化测试环境无 `history` 时安全降级（notification-hook 依赖该环境）。

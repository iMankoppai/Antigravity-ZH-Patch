# v71：Antigravity 2.27.0 适配说明

日期：2026-10-28。管理器版本 1.3.1（覆盖 v1.3.1 标签下此前的内核 v70 构建），汉化内核 v71。随 v1.3.1 发布。

## 官方更新带来的变化

2.27.0 自动更新把 `resources/app.asar` 整体换新，并**移除了 `app.asar.bak` 原件备份**，客户端回到全新未汉化的官方版本。原 2.26.0 补丁与基线随之失效，需要重新适配并重新永久安装（管理器会在安装时重建同版本原件备份，旧版备份不会回填到新版本目录）。

## 归档差分（主进程）

读取本机 2.27.0 官方归档（SHA256 `5ed34675…`，4,560,341 字节）与保存的 2.26.0 原版逐文件比较：

- 变化模块：`dist/main.js`、`dist/ipcHandlers.js`、`dist/utils.js`、`dist/preload.js`、`dist/__mocks__/electron.js`、`package.json`（版本号）。
- 新增模块：`dist/cablev2.js`、`dist/qrEncoder.js`、`dist/webauthn.js`、`dist/webviewBrowser.js`、`dist/webviewWebAuthnPreload.js`、`dist/__mocks__/electron-log/main.js`（WebAuthn/通行密钥与 `<webview>` 弹窗浏览器）。
- `dist/tray.js`、`dist/ideInstall/wizard.js`、`dist/provisionSplash.js` 逐字节未变；`unpacked` 条目集合与 2.26.0 完全一致（347 个）。
- 生产安装器的全部注入锚点在 2.27.0 中仍恰好命中 1 次，引擎无需改动。包签名与 2.26.0 相同（依赖未变）。

## 前端差分与词条

前端 bundle 通过 Chromium 缓存提取并与运行中 2.27.0 客户端的本地服务（`https://127.0.0.1:<port>/main.js`）逐字节核对（10,427,135 字节）。与 2.26.0 bundle 做字面量差分得到 913 个新增字符串，经 UI 过滤得到 125 个候选，逐条在 bundle 中定位上下文后收录 74 条词条（词库 5,894 → 5,963 条）与 8 条动态模板。

覆盖的新界面（证据见 `work/v71/context-probe.cjs` 输出）：

- **语音模式 / 实时通话**：语音选择器（`Choose Jetski's Voice`）、音量与麦克风设置、语音坞（`Start Live Chat`、`End Live chat`、`Mute mic`、`Message this chat`、`Back to chat` 等）、连接状态（`Connecting…`/`Reconnecting…`）、语音风格描述（明亮/欢快/轻快/活泼/青春/沉稳/严谨）。语音名（Jetski、Charon、Kore 等专名）保留英文。
- **Google Drive 集成**：`@drive` 徽标、`Log in`、`Log in to Google Drive`。
- **多账号切换**：设置页中整句被链接/选择器切分的提示（`Signed in as … To use another account, add it in the …` 等 3 种变体），按结构重组翻译，账号邮箱保持原样；新增结构函数 `translateSplitHintSentence`（与 `translatePermissionSentence` 同模式）。
- **浏览器子代理**：动作状态 12 条（`Opening page`、`Going back`、`Clicking`、`Typing` 等）与 `Opening {域名}`、`Pressing {键名}`、`Scrolling {方向}` 模板，域名/键名/方向为受控值原样保留。
- **其余**：环境恢复（`Resume environment`、终端启动与恢复说明）、项目/远程工作区创建引导、模型额度标签（`Daily limit`、`24h limit` 模板）、对话列表空状态与加载态、网页视图截图栏、调试包上传说明、MCP 服务器账号选择器 aria 模板。

## 有意保留（范围纪律）

- bundle 差分命中的 `Owner`、`Merged`、`Ask`、`Function`、`Drive` 等单词，上下文均为 React 内部标识（`ReactCurrentOwner` 等），无 UI 证据，不收录。
- `Attached context:` 拼入用户消息负载，属内容而非界面。
- 终端 ANSI 系统消息（`This chat's environment is paused. Open a new terminal…`、`Connection lost…`）受终端保护规则约束，收录亦不会命中。
- 开发者诊断信息（worker sandbox、URI protocol、storage bridge 等）不翻译。
- macOS 专属 caBLEv2 通行密钥二维码弹窗（`Passkeys`/`Use your phone or tablet`）经 `configurePlatformWebAuthn` 的 `platform !== 'darwin'` 门禁确认不会在 Windows 出现，且该窗口不经过任何 zh-bundle 挂点，列入范围外。
- 跨平台 WebAuthn 通行密钥选择弹窗（`Choose a Passkey`）走 `dialog.showMessageBox`，已接入词典：`Sign in to {站点}` 由 `native-ui.js` 前缀规则翻译，站点标识保留。

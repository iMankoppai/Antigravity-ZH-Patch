# v68 全局漏译修复

适配 Antigravity 2.26.0（Windows x64）。管理器版本继续为 1.2.0，汉化内核升级为 v68，主词库为 5,874 条。本次为本地构建，未上传 GitHub。

## 修复内容

- 新增 9 份内置技能完整正文，共 488 个翻译单元：agy-customizations、antigravity_guide、automation、generative_ui、migrate-workflows、permissioned-github、plugin、run-workflow、ui-plugin-navigation。修复 run-workflow 简介漏译和 plugin 清单表格的非标准续行。
- 内置技能译文绑定冻结原件的 SHA256；运行时按完整 Markdown 长度与指纹匹配。新版本或自定义正文不套用旧译文，保留代码、路径、链接及嵌套列表。原始 React 节点仍保留，支持动态切换与英文还原。
- Electron `showErrorBox` 接入固定标题翻译，保留错误详情。浏览器 `alert` 精准处理钩子配置保存成功提示，支持还原原函数。
- 补齐浏览器配置和调试警告、额度重置倒计时、DNS／连接错误、表单校验、权限确认、附件无障碍名称、消息队列播报、钩子阶段、状态标题和低频工作区入口。
- 修正 Windows 设置的系统托盘措辞，支持 p-4／p-6 设置布局；修复项目与非项目权限说明、Git 提交栏的跨节点语序，并保留点击事件及动态数字更新。
- 对模型额度后缀和侧栏相对时间采用限定上下文的翻译；模型名、对话名和正文中的同形数据保持原样。
- 统一技能筛选器、安装来源、时区占位提示及市场类目的无障碍文案。校正两处技能标题直译及 PDB 简介中的额外增译，清理主词库边界空白键。


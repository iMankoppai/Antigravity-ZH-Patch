# v72：Antigravity 2.28.0 适配说明

日期：2026-10-29。管理器版本 1.3.2，汉化内核 v72。随 v1.3.2 发布。含用户反馈驱动的实机巡航审计轮与热注入缺陷修复。

## 官方更新带来的变化

2.28.0 自动更新再次整体替换 `resources/app.asar` 并移除 `app.asar.bak` 原件备份，客户端回到未汉化的官方版本（与 2.27.0 更新时相同）。管理器会在安装时重建同版本原件备份。

## 归档差分（主进程）

2.28.0 官方归档（SHA256 `4a145127…`，4,615,355 字节）与 2.27.0 原版逐文件比较：

- 变化模块：`dist/main.js`、`dist/ipcHandlers.js`、`dist/beyondcorpPac.js`、`dist/preload.js`、`dist/__mocks__/electron.js`、`dist/webviewBrowser.js`、`package.json`（版本号）。

- `dist/utils.js`、`dist/tray.js`、`dist/ideInstall/wizard.js`、`dist/provisionSplash.js` 与 2.27.0 逐字节一致；包签名不变。
- 生产安装器的全部注入锚点恰好各命中 1 次，引擎无需改动。变化的主进程模块没有新增原生弹窗文案（`Cannot open folder`、`Folder is on the Windows filesystem` 等已有词条覆盖）。

## 前端差分与词条

前端 bundle 提取自 Chromium 缓存（10,647,600 字节，缓存最新条目，2026-10-28 18:11）；客户端当时未运行，改用两条证据交叉验证身份：该 bundle 为缓存中唯一最新条目，且 v71 词典键在其中的保留率约 98%（错误构建不可能达到）。与 2.27.0 bundle 字面量差分得到 1,029 个新字符串，UI 过滤后 100 个候选，逐条定位上下文后收录 77 条词条（词库 6,040 条）并修订 1 条。

覆盖的新界面（证据见 `work/v72/context-probe.cjs` 输出）：

- **webview 站点信息/证书面板**：`Connection is secure`、`Not secure`、证书字段（颁发对象/颁发者/有效期至）与四种证书错误句、隐私提示整句。
- **快捷键设置面板**：搜索、重置（单条/全部）、命令折叠/展开、快捷键录制器（`按下按键…`、`停止编辑`）、浏览器标签页占用提示整句、手势片段（`Click`/`Middle Click`）。
- **命令面板（quick input）**：两组搜索占位符（含 `subagents` 变体）、`Waiting for your approval`（已同步登记状态前缀白名单）。
- **Cog 云工作区**：创建失败三连、`Requires a GitHub repository`、`Loading repositories…` 等。
- **插件连接与市场**：`Connections` 区块、登录状态（已登录/未登录/需要登录）、扩展登录状态上报错误前缀、技能/自定义项可用提示、`Local only`/`Cloud only` 徽标。
- **远程数据删除确认**：两级整句确认弹窗与失败重试提示。
- **外观与链接设置**：Google Sans 字体开关、实验性视觉主题开关、链接打开方式两版说明。
- **其他**：`Open in Side Panel`（DOM 菜单）与原生菜单实际显示的 `Side Panel` / `Side Panel (Default)`（已加入 native-ui 允许清单）、`Open Conversation in New Tab`、`Copy version details`、20MB 文件上限、终端沙箱不支持提示、调试包说明长句更新。

## 实机巡航审计轮（用户反馈）

用户指出输入框工具条 tooltip（`Send Message Enter`）与 `Turbo` 模式名未汉化。使用 CDP 实机巡航审计（与 v70 同方法，工具在 `work/v72/`）：

- **多界面扫描**：对话页、设置全部 13 个分页、快捷键页全量 29 行命令行逐屏扫描可见英文；悬停遍历当前屏全部 `data-tooltip-id` 触发器捕获 tooltip 文本。
- **组合式 tooltip 根因**：base-ui 把 JSX 子树序列化成**单个文本节点**，「已知文案 + 快捷键」的组合串无法被词典精确命中。修复：新增整串模板规则（`Send Message|Queue Message + 快捷键` → `发送消息/将消息加入队列 + 原快捷键`）；静态枚举全部 tooltip content 字面量确认无其他同类缺口。
- **词条补漏**：`Reopen Closed Tab`、`Move Conversation Up`、`Move Conversation Down`、`Live chat`；`Turbo`/`Turbo mode` 修订为「极速/极速模式」（与「默认/整台电脑」译法体系一致）；成果审阅覆盖行 `N projects` 模板；权限选择器 aria 中的模式名改为随词典翻译。
- **实机复核**：`极速`（文本+aria）、`发送消息 Enter` tooltip 均在运行中客户端确认。
- 保留项：主题预设名（Alabaster/Tahoe/Atelier/Studio/Planes）、发布通道名（Dev/Stable）、账户/项目名等用户内容、快捷键键名（`Ctrl`/`Enter` 等）、版本信息弹层的模型/通道名。

## 热注入缺陷修复

实机验证时发现：对**已注入旧内核**的页面直接热注入新内核，页面会同时运行两个实例——旧词典实例的观察器在 React 每次重渲染时把新实例写入的译文"还原"回英文（如 `Turbo` 反复回退）。`CdpHotPatcher.InjectAsync` 现在注入前先调用旧实例的 `__antigravityZhPatchRestore()` 卸载观察器并清除状态，再整体重扫。此缺陷影响所有"运行中热更新到不同词典"的场景；对未注入页面的首次热加载不受影响。

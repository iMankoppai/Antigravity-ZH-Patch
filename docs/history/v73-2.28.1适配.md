# v73：Antigravity 2.28.1 适配说明

日期：2026-10-29。管理器版本 1.3.3，汉化内核 v73。随 v1.3.3 发布。

## 官方更新内容

2.28.1 是纯版本号更新：官方归档（SHA256 `cec1039f…`，4,615,355 字节）与 2.28.0 相比，**唯一变化是 `package.json` 的版本号**——全部 dist 模块逐字节一致，包签名不变，生产安装器的 5 个注入锚点恰好各命中 1 次，引擎与既有词条规则零改动。

2.28.1 更新同样整体替换了 `app.asar` 并移除 `app.asar.bak` 原件备份，需重新永久安装（管理器已重建同版本原件备份）。

## 前端差分与词条

前端 bundle 从运行中 2.28.1 客户端的本地服务逐字节下载（10,652,357 字节，较 2.28.0 增加 4,757 字节）。字面量差分新增 53 个字符串，几乎全部为代码片段、正则与 CSS 类名噪声；真实 UI 变化集中在插件详情页与市场页脚：

- 插件详情页脚「Links」区块：`Website`（网站）、`Repository`（代码仓库，沿用术语表约定）。
- 市场页脚 aria：`Marketplace notice`（市场提示）。

词库 6,044 → 6,047 条（`localization/v73-ui-additions.json`）；v72 词典键在新前端中保留 3,111 / 消失 0。其余新增字面量（`third-party-tools-disclaimer-*` 内部标识、开发者诊断信息）按范围纪律跳过。

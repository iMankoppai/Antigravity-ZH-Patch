# v1.2.0 发布说明

此前本地 v1.1.7 构建统一以 v1.2.0 正式发布。本次同步管理器窗口版本、程序集版本、更新检查版本和下载包版本，翻译内核保持已经验证的 v62。

适配 Google Antigravity 2.24.0（Windows x64），包含 5,638 条界面词条、17 个官方插件的 140 份完整技能详情，以及 6 份规则／智能体详情。

相对于 GitHub 上的 v1.1.0，本次汇总了后续本地修复：

- 翻译完整技能正文，修复 Markdown 表格续行、预览截断匹配与规则／智能体详情漏译。
- 重译 180 条 Web 指南概览，校订 36 段技术正文，修正 Token、数据写入目标、信息依据等术语错译。
- 修复 43 处代码元素、7 处链接文字清空及段落重复；保留真实代码、路径、模型名和用户内容，并支持完整英文还原。
- 补充和校订 207 条固定界面文案、154 类动态提示。
- 提供应用内更新和手动新版汉化适配；保留版本、哈希校验及原版备份保护。

校验范围包括 25 项本地必需检查、140 份正文和 146 份真实 React 详情回归，以及全部 13 份现有插件根 README 的代码、链接与还原检查。完整检查范围及保留项见 [全局汉化复核报告](v1.1.7-全局汉化复核.md)。未逐句人工重校全部 8,966 段，不承诺任意新增或动态内容均已翻译。

下载资产：`AntigravityZhManager.exe`、`Antigravity-ZH-1.2.0-Windows-x64.zip`、`SHA256SUMS.txt`、`release-metadata.json`。独立 EXE 内置 .NET 8 运行时；ZIP 内保留中文文件名 `Antigravity汉化管理器.exe`。两种 EXE 名称对应同一份程序，校验清单分别列出。

发布页：[GitHub Release v1.2.0](https://github.com/iMankoppai/Antigravity-ZH-Patch/releases/tag/v1.2.0)。

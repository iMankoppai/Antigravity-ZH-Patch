# Antigravity 2.23.1 适配说明（v1.0.4）

适配日期：2026-10-15。适用平台：Windows x64。

## 失效原因

官方更新将安装目录中的 `resources/app.asar` 替换为 2.23.1 原版，移除了内嵌汉化脚本。v1.0.3 的基线清单只登记到 2.23.0，会拒绝向未知版本写入。v1.0.4 登记了经核对的 2.23.1 官方基线，支持重新安装与对应版本的英文还原。

## 核对结果

| 项目 | 结果 |
| --- | --- |
| 官方 `package.json` 版本 | 2.23.1，与 EXE 版本一致 |
| 官方 ASAR 大小 | 4,486,221 字节 |
| 官方 ASAR SHA256 | `b8ec3628df2a12ee9deac5dc06367f238065af146bfe6298fdad6db5f9790d9c` |
| 注入锚点 | 15 处，各命中一次 |
| 前端 bundle | 9,902,207 → 9,902,912 字节 |
| 字符串差异扫描 | 新增的 10 项可读字符串候选均为布局 class，未发现新增待翻译界面文案 |
| 汉化内核 | 沿用 v40，3,513 条词库 |

本轮不增加词条或内核版本。管理器产品版本更新为 1.0.4，窗口版本号与本地版本提示同步。版本检测失败时不再显示旧的默认客户端版本。

## 验证与使用

- 86 项浏览器渲染断言检查状态标签、动态文本、内容保护及英文恢复。
- 引擎回归逐一检查所有已支持版本的官方原版，并拒绝使用其他版本的备份恢复。
- 当前窗口热加载已验证：v40、3,513 条、`lang=zh-CN`，菜单与状态标签为中文，模型名及项目名保留原样。
- 永久安装后的 17 项统一检查全部通过；源码与编译资源逐字节一致，安装内核与源码 bundle 一致。
- 隔离副本安装、重复安装、还原英文均通过，还原后的 SHA256 与上表官方原版完全相同。
- 客户端已重新启动，未再次热注入即自动加载 v40 / 3,513 条词库，文件、项目、设置菜单显示中文。
- 本地 EXE 与 ZIP 来自同一次 1.0.4 构建，ZIP 已解压验证文件集合与 EXE 字节一致。发布文件为独立 EXE、Windows x64 ZIP 与 SHA256 校验清单。
- 本机详细证据保存在 `work/2-23-1-probe/`。

使用新版 `Antigravity汉化管理器.exe`，彻底退出客户端后执行【永久安装汉化】。安装器会为 2.23.1 创建匹配的官方备份。遇到不同版本的旧备份时会拒绝覆盖，不能直接把旧版归档恢复到新版目录。

权限申请、沙箱警告、鉴权失败等需要特殊条件触发的界面，仍按既有验收说明逐项人工复核；通用回归通过不代表这些场景均已真实触发。

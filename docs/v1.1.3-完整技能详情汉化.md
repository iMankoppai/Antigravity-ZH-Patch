# v1.1.3 完整技能详情汉化

日期：2026-10-18。Antigravity 2.24.0 Windows x64，管理器 v1.1.3，内核 v58。

本轮覆盖 17 个官方插件、140 份技能详情的完整 SKILL.md 正文。此前的“140 个技能描述通过”只验证了卡片简介和悬浮提示；README 回归覆盖插件说明，均不能证明完整技能正文已汉化。本轮已补上这层独立内容目录和完整正文回归。

界面词库仍为 5,422 条；新增独立正文目录 `Assets/skill-details.json`，含 15,203 个规范化文本片段及各文档匹配信息。316 个网址、路径、产品名、API 标识和技术参数按保留清单处理。公开官方原件用于批量翻译初稿，SDK 正文和关键专业术语另行校对；此流程不在用户使用软件时联网，也没有发送用户会话或文件内容。后续构建使用入库的本地目录，无需在线翻译服务。

原有规则对包含 API key / GEMINI_API_KEY 的父列表项写入简化译文，并把其余后代文本清空，造成详情中的空白代码框和空列表。v58 对详情禁用这种整段替换和短前缀模糊匹配，改为匹配具体官方文档，再逐文本节点应用对应译文。代码、命令、路径和链接地址保持原样；未知文档和用户/智能体正文不使用该摘要规则。

Google Antigravity SDK 的安装检查、依赖、API 密钥、标准模式、快速模式、本地模型及后续参考索引均已补齐。原文件中给智能体使用的指令保留原样，仅在详情展示时翻译。

验证使用 140 份真实正文 HTML，覆盖：

- 全部正文片段的精确译文。
- 代码原文、链接地址、节点数量与嵌套列表的完整性。
- v57 已清空部分节点时，热升级后恢复原始代码与子列表。
- 未知文档、用户/智能体内容保护。
- 一键英文还原后，140 份正文 HTML 与原始样本完全一致。

`tests/renderer/skill-details-regression.cjs` 共 982 项断言；`tests/localization/skill-detail-quality.cjs` 验证文档数量、原件哈希、非空译文、保留清单、占位标记和目录签名。两项均纳入统一检查入口。原始插件文件的哈希同时核对，未修改任何官方技能指令文件。

正文目录同时嵌入永久补丁与热加载管理器，并纳入资源一致性检查。当前窗口可热更新；重启后的持久生效仍需退出客户端，再用新版管理器点击“永久安装汉化”。深层 references/examples 文件在这些详情中作为代码路径保留，没有将未打开的参考文件冒充本轮正文覆盖。

本轮证据和 SDK 离线预览位于 `work/skill-detail-audit/`。本地交付，未发布 GitHub。

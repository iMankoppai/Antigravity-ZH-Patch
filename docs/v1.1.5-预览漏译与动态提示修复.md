# v1.1.5 预览漏译与动态提示修复

2026-10-19，适配 Antigravity 2.24.0，内核 v60，界面词库 5,422 条。

实机复现了 `/gemini-omni-flash-api` 简介为中文而正文仍为英文。原因是官方插件预览接口将长正文截到 24,000 个 UTF-8 字节，并添加 `<truncated N bytes>`；v59 仅匹配完整正文指纹。现为全部 140 份详情生成完整正文及精确截断预览标识，覆盖其中 9 份长文档。预览长度、内容指纹及省略字节数必须匹配；修改后的未知正文不会被旧译文覆盖。匹配成功后展示本地完整译文。

使用 React 当前已提交的 Fiber 查询正文，避免 DOM 节点复用后读取旧 props。新增与实际客户端一致的 React 18.3.1 测试依赖及来源校验记录，验证全部 140 份预览、节点复用和源文档变化。旧回归手动模拟 Fiber，未覆盖真实组件的交替提交及截断预览，因此之前的通过结论不足以证明实机正文会生效。

删除项目卡片中，只有第一个强调字段是用户项目名称，第二个是动态对话计数。v59 错误保护了两个字段，导致计数漏译；现分别处理，并补上单复数、活跃与归档组合、零值、句号及动态更新的检查。实机读取到“1 个活跃对话和 1 个已归档对话”，项目名保持原样。

Gemini 概览改用保留行内节点的翻译，修复整段改写与子节点翻译竞争造成的重复文字、空代码和空链接，以及 API 密钥说明重复编号。真实概览 DOM 回归覆盖旧版空白节点热升级与精确还原。视频技能另有 46 处人工校订，包括模型名称、首尾帧、重绘与扩图、音频和快速切镜等用语。提示框的英文及中文 Markdown 标记统一渲染为中文标签。

本轮没有逐句重校全部 8,966 个段落，代码、命令、模型标识和可复制的原始提示词示例仍保留原文。深层 references/examples 文件不在技能正文翻译范围。

当前运行窗口已热加载 v60；客户端运行期间未改写安装目录 ASAR，磁盘仍为已验证的 v59。彻底退出 Antigravity 后，使用根目录新版管理器执行永久汉化。正式交付为本地 v1.1.5 EXE 和 ZIP，未上传 GitHub。检查与实机证据见 `work/detail-audit-v60/`。

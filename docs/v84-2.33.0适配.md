## 0. 结论：本次是**功能性大版本**，不是纯版本号更新

2.32.2 → 2.33.0 引入了大量**桌面控制 / 远程**相关主进程模块（`computer/`、`computerActuator/`、`desktopHost/`、`remote/`、`actuator/`、proto 等），且渲染端 `main.js` 从 12,061,895 增长到 **12,353,230** 字符（新增字面量 1,966 个）。因此本次需要：

1. **改引擎锚点**（`utils.js` 关闭到托盘/attach 锚点因新增 `registerPreviewViewer` 调用而失配；`remote/disconnectedPage.js` 结构被完全重写）；
2. **新增词条与动态规则**（内置浏览器 Cookie 管理、浏览器操作步骤、麦克风听写、插件包/初始化例程、远程浏览器提示等）。

### 1.1 引擎改动（`AsarCleanPatcher.cs`）

1. **`dist/utils.js` 关闭到托盘/attach 锚点**：2.33.0 在 `createHubWindow` 尾部 `void win.loadURL(url);` 之前新增了 `(0, previewViewers_1.registerPreviewViewer)(hubContents);`，旧锚点 `"    }\n    void win.loadURL(url);\n"` 命中 0 次。已改为**双锚点**：
   - 优先匹配新稳定尾部 `"    void win.loadURL(url);\n    return win;\n"`（命中 1 次），注入时去掉原处理体前导 `    }` 并在末尾补回 `    return win;`；
   - 旧锚点保留兜底，兼容 2.32.x 及更早版本。
2. **`dist/remote/disconnectedPage.js` SSH 断线页**：2.33.0 将其重构为 `BUTTON_LABELS` + `title/heading/body` 三段表达式。旧锚点（`const title = connecting ? 'Reconnecting…' : 'Disconnected';` 与 `<a class="button primary" …>Reconnect</a>`）已不存在。已改为**按版本分支**：检测 `stop: 'Stop Server'` 判定新版，逐条替换 `Reconnect/Stop Server/Close`、`Restarting…/Reconnecting…/Disconnected`、`Restarting the Antigravity server on ${host}…`、`Reconnecting to ${host}…`、`Disconnected from ${host}`、body 各句与 `<html lang="en">`；旧结构分支保留。

其余锚点（`ipcHandlers` 两个标题 + 右键菜单标签 2 次、`main.js` electron 导入 / deep link / loadURL(newUrl)、`utils.js` setAppDetails（新旧双锚点）/ showQuitConfirmation / 工具窗口 loadURL、`tray.js` 五处、`ideInstall/wizard.js`、`provisionSplash.js`）全部命中 1 次。

证据：`work/2-33-0-probe/`（`asar-diff.cjs` / `asar-diff.json` / `anchor-check.cjs` / `count-anchors.cjs`）。

# Antigravity 2.24.0 适配说明（v1.1.1）

适配日期：2026-10-17。适用平台：Windows x64。

## 失效原因与改动

官方更新将安装目录的 `resources/app.asar` 替换为 2.24.0 原版，内嵌汉化随之移除。现有管理器登记到 2.23.1，自动兼容功能只接受原生模块完全一致的同一主次版本后续补丁版，不能自动跨到 2.24.0。本次登记新版原件基线，保留版本与哈希校验。

| 项目 | 结果 |
| --- | --- |
| ASAR `package.json` 版本 | 2.24.0 |
| 官方 ASAR 大小 | 4,486,221 字节 |
| 官方 ASAR SHA256 | `bd10a0054ca3ad469142b2c2757566493ecc0afb934b9a61ce45d38a4d09316e` |
| 相对 2.23.1 的 packed 条目变化 | 仅 `package.json`；全部 15 个安装注入锚点各命中一次 |
| 缓存中的新版前端 bundle | 9,902,912 → 10,095,222 字节 |
| 字符串差异初筛 | 532 项新增候选，包含 CSS、协议及库内部文本，不能等同于界面词条数量 |
| 管理器 / 汉化内核 / 词条数 | v1.1.1 / v41 / 3,613 |

新增 100 条界面词条，覆盖上下文窗口额度说明、云端运行、自动化凭据刷新、系统通知、浏览器菜单和首次引导。程序内部标识、MCP 协议字段、模型名称和推理档位保留原文。

新版子代理状态标题不含 `flex-row`，现兼容此结构，翻译启动状态、数量与动态拆分文本节点；子代理名称按 `group/agent-ref` 保护。正文、代码、文件名保护规则继续生效。权限说明增加“在这些对话中”范围，上下文窗口提示保留档位名称。

- 引擎检查 106 项通过，其中手动新版适配 38 项；真实归档副本验证安装、重复安装、选项变更、备份轮换、错版拒绝与还原。
- 使用生产管理器编译程序集再次执行隔离安装、重复安装和英文还原；还原结果与本版官方原件逐字节一致。
- 统一入口共 17 项检查通过（含 3 项环境检查），失败与跳过均为 0；源码、编译内嵌资源与本机安装内核一致。
- 本机永久安装后重新启动，未热注入即自动加载 v41 / 3,613 条词库，页面语言为 `zh-CN`；文件、查看、窗口、自动化、设置等菜单为中文，模型名和项目名保留原样。实际加载的前端 SHA256 与本次审计文件一致。
- v1.1.1 管理器已替换并启动，ZIP 解压校验与根目录 EXE 字节一致。交付包仅在本地生成，未上传 GitHub。
- 详细证据保存在 `work/2-24-0-probe/` 与 `当前状态.json`。

## 使用

退出 Antigravity 后，运行本地 v1.1.1 `Antigravity汉化管理器.exe` 并点击【永久安装汉化】或【新版汉化适配】。本次本机安装完成后，直接启动客户端即可自动加载中文。`app.asar.bak` 保存本版对应原件，请勿用旧版本备份覆盖新版。

权限异常、云端凭据过期等需要特殊条件的真实界面未逐一触发；词库和模拟 DOM 回归通过不代表这些场景均已现场验收。

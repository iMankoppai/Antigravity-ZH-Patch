## 本次更新内容

Antigravity 2.33.0 是一次**功能性大版本**，`app.asar` 由 1,068 个文件变为 1,156 个（新增 90 / 删除 2 / 改动 114），新增桌面控制与远程相关模块。汉化补丁相应做了引擎与词库适配：

- **引擎锚点适配**
  - `dist/utils.js` 的「关闭到托盘 / 注入」锚点因官方新增 `registerPreviewViewer` 调用而变更，改为匹配 `void win.loadURL(url);\n    return win;`（旧锚点保留兜底，兼容 2.32.x）。
  - `dist/remote/disconnectedPage.js` SSH 断线页被官方重写为 `BUTTON_LABELS` + `title/heading/body` 结构，已按新结构注入中文文案（含「停止服务器」按钮）。
- **新增界面汉化（97 条词条 + 8 条动态规则）**
  - 内置浏览器：浏览数据、按站点 Cookie、搜索站点、清除历史与站点数据等。
  - 浏览器操作步骤：加载中 / 无记录 / 任务仍在运行 / 截图。
  - 麦克风与语音听写：各类错误提示、转录中、停止转录。
  - 插件包与初始化例程：添加 / 移除 / 评审 / 单独安装 / 已不可用 / 保存删除状态。
  - 附加问题（Side Question）、远程 SSH 主机浏览器提示、设置项 `Enable Browser Agent` 等。
- **基线与安装**：登记 2.33.0 官方原版 `b33c8160…`（6,473,373 字节）与已知补丁版 `fe110b0a…`（18,473,386 字节）。

## 安装 / 升级说明

1. 官方自动更新会替换 `app.asar` 并删除备份，导致汉化失效——这是正常现象。
2. 更新 Antigravity 后，退出客户端，运行本管理器并执行「永久安装」即可恢复中文；也可在运行中点击「新版汉化适配」热恢复。
3. 本次已在开发机对 2.33.0 完成永久安装与全量门禁验证；建议安装后重启客户端确认。

# 深层界面与现场验收清单

用途：无界面环境无法触发的场景，必须由人在真实客户端逐项验收。
配套：`docs/项目维护与交付指导书.md` 第 3 节、第 5.3 节。

记录格式：日期、客户端版本、内核版本、场景、结果（通过 / 失败 / 未测试）、截图文件、原始文字、实际文字、备注。
证据目录建议：`work/acceptance/<客户端版本>-<内核版本>-<日期>/`。

## 判定

发布判定使用三个状态：**可发布 / 不可发布 / 待验收**。
- 必需测试失败 -> 不可发布。
- 必需现场项缺失 -> 待验收。
- 只有全部必需条件满足 -> 可发布。

不得因为自动化检查通过就跳过着现场项；也不得在缺少证据时补写“通过”。
